# Model provider marks

The Mac model sign-in buttons identify the chosen service with monochrome vector marks. OpenAI and Anthropic marks come from the Simple Icons 11.15.0 source distribution (CC0-1.0):

- https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/openai.svg
- https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/anthropic.svg
- https://github.com/simple-icons/simple-icons/blob/11.15.0/LICENSE.md

The original SVG paths are preserved in `Apps/MacApp/Desktop/Assets.xcassets` and rendered as template images. They identify the service selected by the user; MoMo Agent retains its own brand mark. The generic API entry uses the system key symbol.
