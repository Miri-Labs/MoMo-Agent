# MoMo Agent 配色、图标与排版

当前应用图标已按 2026-10-30 用户要求统一改为正面睁眼的 MoMo Avatar，资源与导出方式见[当前品牌](momo-agent.md)。下方图标选择与设备验收均为历史记录；原 M 素材不再参与当前图标导出。

2026-10-14，采用用户提供的调色盘与图标。`palette-reference.png` 与 `app-icon-source.png` 保存本次提供的图像，图标不重绘、不重新着色。

| 色名 | sRGB | 用途 |
| --- | --- | --- |
| 奶油白 | `#F3EEE5` | 浅色内容块、深色文字与控件符号 |
| 纸白 | `#F7F4EE` | 浅色页面底色、浅色模式主要按钮内的反色符号 |
| 墨色 | `#302C26` | 浅色文字、深色内容块与控件表面 |
| 夜色 | `#161512` | 深色页面底色、深色模式主要按钮内的反色符号 |

共享资源位于 `Apps/Shared/BrandAssets.xcassets`，`MoMoPalette` 提供下列三个语义颜色：iPhone 使用动态资源，Watch 固定采用深色对应值，不新增主题状态或业务依赖。

| 语义颜色 | 浅色 | 深色 |
| --- | --- | --- |
| `canvas` | 纸白 | 夜色 |
| `surface` | 奶油白 | 墨色 |
| `ink` | 墨色 | 奶油白 |

iPhone 跟随系统外观；Watch 保持深色。当前 watchOS 资源编译器省略了 named Color 的 luminosity 变体，实际截图曾呈现浅底和低对比 toolbar，因此 `MoMoPalette` 在 watchOS 明确使用对应夜色/墨色/奶油白的 sRGB 值，手机仍使用动态颜色资源。继续使用系统控件、原生 Liquid Glass、动态字号和现有无障碍标识。录音红点、错误与警示保留系统语义颜色。主文字与不透明页面/内容块的计算对比度为 12.00–15.80；这不替代对玻璃、禁用状态与实际页面的视觉检查。

两端 AppIcon 都从同一原图按比例导出 1024 × 1024 的不透明 PNG，只调整资源尺寸；不预先裁圆角或圆形。各 target 的 `Assets.xcassets/AppIcon.appiconset` 使用平台通用图标槽，`project.yml` 显式指定 `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon`。iPhone 圆角与 Watch 圆形遮罩由系统处理。

本次视觉调整包括颜色、图标资源及用户提供的 [Watch 录音界面参考](watch-layout-reference.png)。主屏保留系统时间，左上电脑图标打开传输与录音信息，右上更多入口包含结束录音及系统确认；录音时长移至信息页。底部“静音”调用既有暂停操作，暂停后明确显示“已暂停”和“继续”；不会伪装为仍在采集静音音频。转写、Agent、档案及同步业务不由视觉布局修改。

## 整体排版与手机网页参考

用户随后要求参照 ChatGPT 手机网页调整整体设计，不只更换字体。[独立参考记录](mobile-web-reference.md)区分公开匿名页面的实际 computed style 与原生选择：正文、输入和侧栏为系统字体栈 16px / 24px / 400，首页标题为 24px / 28px / 400，侧栏 24px 内距与 44px 行高。没有确认实际应用 OpenAI Sans，也没有观察登录后的回复气泡。10 个已取公开资源为 2 CSS + 8 JS，[清单](mobile-web-reference-assets/bundle-manifest.json)仅记录来源、大小和 SHA；原始 bundle 保留于本机忽略目录。

iPhone 的 `PhoneTypography` 用系统字体与 Dynamic Type：正文/导航 16pt regular，品牌 18pt semibold，页标题 24pt regular，阅读标题按 24/20/17pt 分层，说明 13pt、次级信息 12pt；代码才使用等宽字体。正文额外行间距为缩放后的 4pt，`lineSpacing` 不是 CSS 固定行高。空首页采用居中的可滚动欢迎区，输入框按焦点/草稿展开并保留视图身份；侧栏采用 24pt 内距、至少 44pt 行高，长计划标题放入正文，设置和资料采用同一文字角色。保留原生导航、系统控件、Liquid Glass、既有 AX 标识及语义警示色。

## Watch 原参考布局的实际对齐与历史验收

[已接受的真实录音截图](watch-recording-accepted.png) 来自 SE3 44mm、watchOS 27 模拟器，使用正式采集路径与 BlackHole 输入公开测试音频，未经修图。该图原始路径为 `tmp_agent_output/20261014-watch-blackhole-e2e-06/preview/recording.png`；对应 `CaptureView.swift` SHA-256 为 `f2af669827de9fa6fe7374e41e287fd853f57c2b0cda12b7c5d2d22893ce928a`。

- 实屏为 368 × 448 px，点阵可见范围约 319 × 159 px，29 列 × 15 行，横纵点距约 11 px。测量为截图中节点边缘的近似范围，不是固定设备尺寸或逐像素复刻承诺。参考比较排除了照片中的表壳和表带。
- 正常字号主屏不滚动，保留原生顶部工具栏与系统时间，不覆盖顶部安全区；仅向底部容器安全区扩展，内容再保留 4pt 底部间距。接受图底部标签完整、离屏幕底缘约 15px。大字号、错误和容量提示使用滚动回退；本轮普通字号截图不能替代所有字号与 Watch 尺寸的验收。
- 普通字号的圆钮视觉直径为 32–40pt，图标约占圆径一半；圆钮与文字共同位于至少 44 × 44pt 的按钮命中区域内。玻璃表面采用墨色，符号采用奶油白，录音状态保留红点。
- 点阵保留最近 29 个真实 RMS 展示值，每秒更新 10 次。幅度经单调四次根映射决定高度，仅满幅才达到最大值，按垂直距离衰减点径和亮度。没有固定双峰或随机声波；不同输入的轮廓不要求与参考照片相同。
