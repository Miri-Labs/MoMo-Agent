# 交互研究检查清单

2026-10-15。已完成的外部实测、未验证范围与证据见 interaction-research.md；本清单保留为后续原生实施的覆盖范围。

| 区域 | 要观察的行为 | 要记录的证据 |
| --- | --- | --- |
| 用户消息 | 短句、长段落、多行、编辑、复制 | 对齐、最大宽度、内距、圆角、换行、操作显隐 |
| 助理消息 | 纯文字、列表、引用、代码、表格 | 有无气泡、正文宽度、块间距、横向溢出策略 |
| 发送 | 空输入、已填入、发送后、附加来源 | 按钮状态、草稿清空时机、焦点与键盘策略 |
| 首字出现前 | 等待、取消、错误 | 状态符号、是否预留正文高度、是否伪造进度 |
| 流式回复 | 小块、大块、间歇、含中文与 emoji | 到达节奏与视觉呈现节奏、尾部动画、布局抖动 |
| Markdown 流 | 半个粗体、未闭合代码块、增长中的列表 | 中途排版、完成后收敛、历史内容是否重排 |
| 停止 | 首字前停止、回复中停止、立即再发送 | 已收到内容保留、状态命名、旧回调隔离 |
| 重试 | 连接中断、完整回复后重新生成 | 重试入口、是否重复用户消息、分支表达 |
| 滚动 | 跟随最新、向上阅读、回到最新、键盘打开 | 自动跟随触发条件、读者位置保持、回到底部入口 |
| 可访问性 | 减少动态效果、键盘、读屏 | 动画降级、焦点、状态播报频率、控件可达 |
| 参考网站 | 移动菜单、展开收起、示例切换、输入状态 | 点击路径、过渡、状态是否有反馈 |
| 第三方 bundle | 组件状态与流式实现 | 来源 URL、实际模块、可核对的代码位置与许可信息 |

## 当前项目的已核对事实

原生 `AssistantView.swift` 已使用右对齐的用户浅色气泡、无底色的助理正文，发送按钮在繁忙时切换为停止。`MarkdownReadingView` 接收完整累计 Markdown 文本；会话滚动目前在消息数量变化时调用 `scrollTo`。这些是代码观察，不代表浏览器参考行为或原生交互验收。

当前可点击稿已补充固定示例的实时演示：等待、增长、停止、中断、重新生成与滚动脱离跟随。它不调用模型 API。外部 Claude 的生成、停止与向上阅读已实际操作；外部 Claude 的重新生成未操作，ChatGPT 的真实流速和停止结果未验证。其余逐项记录见交互研究报告。

当前评审入口统一为 momoagent-iphone-review-v8.pen。网页演示及运行脚本已移除；清单中的演示检查为历史证据。
