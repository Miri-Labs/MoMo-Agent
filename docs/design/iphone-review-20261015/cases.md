# MoMoAgent iPhone 场景清单

220 个设计场景，15 类。它们是预期行为与恢复路径，不代表已实现或通过测试。29 屏草稿覆盖代表状态；其中播放器为本轮待评审提案。没有独立计划页或服务商专属配置页。

## 入口与首次使用

- C001 首次打开：说明手表录音、本机转写、助理三者关系；允许先使用录音与转写。
- C002 没有模型配置：在需要助理时引导连接服务，保留查看录音入口。
- C003 已有配置但没有聊天：保留原有简约空白首页与输入区；聊天页不放模型选择器，服务与模型在设置管理。
- C004 已有聊天：恢复原会话和滚动位置；侧栏以左侧抽屉覆盖，点击外侧回到原会话，不误建新会话。
- C005 没有手表状态：显示等待手表状态和打开手表 App 的提示。
- C006 没有任何转录：显示如何从 Watch 开始；不显示虚构摘要或进度。
- C008 原有配置升级：保留可用连接；需要迁移时解释并允许稍后处理。

## 服务商与密钥

- C009 选择预设服务：预设只填入 API 地址与协议，所有服务进入同一通用连接与模型验证流程。
- C010 使用 OpenAI 协议服务：按所选协议填写基础地址，复用通用表单与验证，不触发服务商专属模式。
- C011 选择 Anthropic：使用 Messages 协议，模型目录与凭证随服务商隔离。
- C012 选择自定义服务：永久标签说明服务名称、HTTPS 地址、协议、密钥。
- C013 服务商与订阅不匹配：说明聊天订阅与 API 凭证不同，提供正确的获取入口。
- C014 凭证与服务地址不匹配：在通用连接页说明凭证或地址不匹配，保留输入供修改，不新增地域或品牌专属页面。
- C015 凭证类型与接口不匹配：说明当前凭证或接口类型不受所选协议支持，保留输入；不按服务商单独实现套餐兼容。
- C016 空密钥：字段内提示必填；已有有效密钥的连接编辑另有保留语义。
- C017 密钥前后含空格：去掉外围空白；不改动密钥内部字符。
- C018 粘贴密钥：默认遮挡，键盘不自动纠错、不自动大写。
- C019 显示密钥：显式按住或切换可见性；离开页面恢复遮挡。
- C020 已有密钥：展示已保存状态与掩码，不读取旧密钥回填可编辑文本。
- C021 更换密钥：先验证新草稿，成功前保留原连接。
- C022 取消更换密钥：撤销草稿，原密钥和当前模型继续可用。
- C023 钥匙串读取失败：说明当前无法读取凭证，提供重试；不称为密钥无效。
- C024 钥匙串写入失败：不宣称连接已保存；保留草稿并让用户重试。
- C025 重复添加同一服务：识别已有连接，提供编辑或明确的第二连接名称。
- C026 切换服务商时有未保存修改：保留各自草稿或明确确认丢弃，不能默默覆盖地址与模型。
- C027 返回时有未保存修改：提供保留编辑或放弃；已保存配置不受影响。
- C028 移除正在使用的连接：先选择替代模型，或明确助理将不可使用；录音与转写继续。
- C029 移除非当前连接：明确只删除该连接凭证，聊天、录音和计划仍保留。
- C182 首次不预选服务商：初始服务商、模型均为空，列表无勾选项；连接前仍可使用录音与转写。
- C183 选择 DeepSeek：预填 https://api.deepseek.com 和 Chat Completions 协议；不显示地域。
- C184 选择 Kimi：预填 https://api.moonshot.cn/v1；密钥帮助指向 Kimi 官方平台。
- C185 选择智谱 GLM：预填通用 API 地址，不把 Coding 套餐端点作为通用默认地址。
- C186 选择硅基流动：预填 https://api.siliconflow.cn/v1；模型列表使用该平台返回的 ID。

## 地址与协议

- C030 地址为空：字段旁提示填写服务商文档提供的 API 地址。
- C031 地址格式错误：指出格式错误，保留输入，不笼统归因于密钥。
- C032 非 HTTPS 地址：按当前运行时契约提示只支持 HTTPS，不静默绕过验证。
- C033 地址含用户名或密码：提示凭证应填 API Key 字段，不放在 URL 中。
- C034 地址含查询参数或片段：指出不支持的部分，保留可修改草稿。
- C035 地址缺少路径：预设自动补齐；自定义按服务商文档显示明确示例。
- C036 重复拼接 /v1：预览实际请求基地址，避免二次追加。
- C037 自定义地址覆盖预设：允许在同一连接设置修改基础地址；预设不绑定地域或隐藏兼容模式，修改后重新验证。
- C038 切换接口协议：清楚区分 Chat Completions、Responses、Messages；成功前不覆盖原连接。
- C039 更改地址后：旧验证结果失效，必须重新验证。
- C040 服务需要额外鉴权头：当前不支持时明确说明，不把无法配置的字段藏进通用错误。
- C187 通用配置不设地域：所有服务共用名称、API 地址、密钥、协议和模型字段，不提供地域或服务商专属兼容开关。
- C188 修改 API 基础地址：在通用连接设置中编辑地址，采用所选标准协议重新验证，不创建品牌专属地址页。
- C189 切换协议的地址变化：兼容 Chat Completions、Responses、Messages 不代表基础地址相同；修改后重新验证。

## 连接验证

- C041 开始验证：按钮进入忙碌状态，说明正在验证的对象，原输入保留。
- C042 连续点击验证：只保留一次在途请求，避免重复测试和计费。
- C043 取消验证：停止本次请求，原连接不改变。
- C044 验证时返回上一页：取消页面草稿任务或明确后台继续；后返回的结果不得覆盖另一份草稿。
- C045 验证时切到后台：恢复时显示真实状态；过期请求可重试，不无限转圈。
- C046 离线：显示网络不可用，允许保留输入后重试。
- C047 DNS 失败：提示无法找到服务地址，优先检查地址或网络。
- C048 TLS 或证书失败：说明安全连接失败，不提供关闭证书检查的捷径。
- C049 连接被代理阻断：提示网络无法访问该服务，保留原配置。
- C050 请求超时：保留草稿，提供重试；不立即认定密钥有问题。
- C051 401 未授权：提示检查或更换密钥，提供获取入口。
- C052 403 无权限：说明服务或模型权限不足，区分密钥格式错误。
- C053 余额不足：说明服务商额度不足，引导查看对应平台计费信息。
- C054 429 限流：显示可重试时间或等待说明，禁止无间隔自动重试。
- C055 5xx 服务异常：说明服务商暂不可用，允许稍后重试。
- C056 404 路径错误：指出 API 地址或协议可能不匹配。
- C057 返回 HTML 或无效 JSON：说明服务响应不符合所选协议，保留具体问题分类。
- C058 服务不支持模型枚举：不判为连接失败；允许预设目录或手动模型 ID。
- C059 枚举成功但推理失败：明确模型仍不可用，不把列出模型等同于验证完成。
- C060 最小请求返回工具能力不支持：说明该模型无法满足助理需求，允许选择其他模型。
- C061 验证成功但保存失败：显示连接通过、配置未保存两个事实，允许重试保存。
- C062 验证成功：显示服务、模型、验证时间；明确保存与使用的下一步。
- C063 过期验证结果：草稿修改后旧结果不再授权保存，不错误显示绿色成功。
- C193 目录可读但调用被拒绝：读取目录成功不等于模型权限通过；选择模型后做独立验证，说明可能计费。
- C194 新服务验证失败：现有可用服务与模型继续保留，草稿错误不覆盖正式配置。

## 模型目录与切换

- C064 目录加载中：保留已有可用模型，显示局部加载状态。
- C065 搜索模型：匹配名称和 model ID，不搜索其他未连接服务。
- C066 搜索无结果：提供清空搜索或手动添加模型入口。
- C067 目录为空：解释未返回可用模型，提供重试与手动添加。
- C068 目录读取失败：保留当前模型，允许重试，不清空原选择。
- C069 手动输入 model ID：标签和示例清楚；添加后验证权限与协议。
- C070 模型 ID 不存在：明确指出模型找不到，允许修正或换模型。
- C071 模型无调用权限：提示开通权限或换模型，不要求盲目重填正确密钥。
- C072 选择模型但未确认：只更新选择草稿，返回后实际使用模型不变。
- C073 确认新模型：影响后续新消息，已有聊天与来源保留。
- C074 请求进行中切换模型：在设置中更改模型；当前请求使用启动时的模型快照，新模型作用于后续请求。聊天页不重复放选择器。
- C075 原模型被下架：解释不可用，保留会话并引导选择替代模型。
- C076 服务商多个同名模型：同时展示所属服务，避免仅用显示名误选。
- C190 首次不预选模型：服务连接后，用户选择并验证模型，才用于新消息。
- C191 不提供模型目录：目录不可用不直接判定密钥错误；保留手动填写模型 ID 与重试。
- C192 模型 ID 更新或停用：优先读取实际目录；预设地址不绑定永久模型清单，不悄悄换成另一个模型。

## 聊天与请求

- C077 输入为空或只有空白：发送不可用，提供可理解的禁用状态。
- C078 多行长输入：输入框按原有规范扩展，操作区保持可达。
- C079 键盘打开：输入区随安全区移动，不遮挡发送和已选来源。
- C080 正在回答：显示忙碌状态与停止入口，正文按实际流式内容增长。
- C081 尚无首字节：显示等待状态和取消能力，不伪造文字进度。
- C082 停止回答：保留已收到文字并标为未完成，输入可以继续。
- C083 流中断：保留部分回答与来源，提供同一请求的重试。
- C084 请求超时：保留草稿或失败请求，不丢失用户输入。
- C085 限流等待：显示等待条件，重试按钮在允许时恢复。
- C086 取消旧请求后发新消息：旧回调不能污染新消息或新会话。
- C087 新建聊天时仍在回答：明确停止或保持原请求，避免静默切换所有权。
- C088 切换历史聊天：按会话隔离加载与错误，不把上一会话回答插进当前会话。
- C089 长回答与代码：可阅读、选择复制，横向内容不挤坏整页。
- C090 用户向上阅读：新内容不强制把人拉回底部，提供回到最新位置。
- C091 无可用近期转录：直接说明上下文不足，允许普通讨论，不编造来源。

## 来源与录音引用

- C092 从详情进入聊天：附加可移除来源，等待用户编辑并发送。
- C093 移除草稿来源：仅移除本次引用，不删除录音。
- C094 多次点击提问：不重复附加同一来源或重复发起请求。
- C095 引用的转录发生修改：发送前重新校验，提示内容已更新。
- C096 引用的录音已删除：提示来源不可用，允许移除后继续，不使用旧副本。
- C097 读取过多个来源：只在采用对应事实时由模型生成行内链接；不把读过的全部来源自动追加为列表。
- C098 点击正文行内引用：校验 citationURL 对应的 session、span、version、generation 后打开原文；引用失效明确说明，不能误跳到别的片段。
- C099 原音已清理但文字还在：来源仍可读和讨论，明确不能回听。

## 手表状态与波形

- C100 手表正在录音且状态新鲜：保留原有黑色点阵波形卡，红点与文字共同表达录音中。
- C101 手表静音：保留卡片和低活动波形，明确静音而非结束。
- C102 手表准备录音：显示准备状态，不能提前宣称正在采集。
- C103 手表已结束：显示未在录音；是否同步完整由独立数据判断。
- C104 缓存状态或状态过期：显示上次更新时间与待更新，不把缓存作为实时证据。
- C105 手表称录音中但无新采样：显示等待声音采集，避免假装持续正常录音。
- C106 手表录音中断：保留资料并说明需要在手表处理。
- C107 手表录音失败：显示停止与下一步，不能继续绘制正常实时反馈。
- C108 未安装或未打开手表 App：说明从哪里开始，允许使用已有手机资料。
- C109 多个手表或重新配对：明确当前资料与设备归属，不能把旧设备状态当新状态。
- C110 减少动态效果：保留波形静态形态与状态文本，停止非必要运动。

## 音频同步

- C111 录音中持续收到片段：按已收到的资料更新，列表不频繁跳动。
- C112 只有状态尚无音频：显示手表状态，不生成虚假的可播放录音。
- C113 手机离线仍可本地传输：分别表达网络和手表传输状态，云端失败不阻塞本机资料。
- C114 已知有片段未到达：说明仍有录音未传到手机，已收到内容可先阅读。
- C115 收到数量与处理数量相等：只说已收到内容已处理，不推断手表全部同步完成。
- C116 重复或乱序片段：不重复展示录音；内容位置以真实映射为准。
- C117 同步文件冲突：指出受影响的资料和明确恢复入口。
- C118 文件缺失：显示可理解的缺失状态，保留可用正文和原音。
- C119 手机空间不足：暂停不能安全完成的接收或处理，提供容量管理。
- C120 删除后的迟到片段：不复活已删除资料，界面保持删除结果。

## 本机转写

- C121 本机模型尚未就绪：自动准备所需资源；在受影响录音旁显示正在准备，不提供模型管理或就绪开关。
- C122 本机模型文件缺失或损坏：自动修复或重新准备资源；无法恢复时在受影响录音旁说明原因，不暴露模型管理设置。
- C123 等待音频：显示已知等待条件，不使用伪百分比。
- C124 分析语音中：说明正在分析，不把它等同于文字已完成。
- C125 正在转写且已有文字：正文继续可读，明确文字还会更新。
- C127 系统暂停：系统条件满足后自动继续；在受影响录音旁说明暂缓原因。
- C128 系统结束且原因未知：保留队列并在 App 可运行时自动恢复，不要求用户点击继续转写。
- C129 某段失败：失败段提供对应恢复入口，其他正文继续可读。
- C130 未检测到语音：说明未发现说话声，原音可用时仍可回听。
- C131 转录连续被修改：保存任务并解释何时可重试，不无限覆盖原文。
- C132 处理批次部分原音已删除：已删除时长与已处理时长分开，不伪装为处理完成。
- C133 全部已收到内容转写完成：清除过期进度；仍不宣称 Watch 完整同步。

## 录音阅读与回听

- C134 很短的转录：正文自然留白，不强塞摘要或任务卡。
- C135 很长的转录：按段落与真实时间阅读，返回后恢复位置。
- C136 转录疑似识别错误：原文如实显示，不能用设计改文案的名义纠错。
- C137 时间映射缺失：不伪造精确时间或连续音频进度。
- C138 原音可用：显示清楚的回听与停止状态。
- C139 部分原音过期：受影响段落禁用回听，其他段落仍可用。
- C140 全部原音已清理：隐藏可用播放按钮，保留文字与提问。
- C141 回放启动失败：错误显示在发起回放的位置，允许重试。
- C142 播放中异步失败：及时结束播放状态，保留正文和定位。
- C143 切换段落播放：取消或结束旧播放，避免多个播放器重叠。
- C144 切到后台或音频被打断：遵守音频会话状态，回前台显示真实暂停或停止状态。
- C215 主播放器位置：录音日期和已收音频信息下方、正文上方；阅读时吸附在导航下方，不遮挡底部提问。
- C216 暂停后续播：保留目标和精确位置，点击继续从原处播放；停止清空不能冒充暂停。
- C217 暂停状态拖动：拖动预览时间，松手定位后仍暂停，不意外发声。
- C218 播放状态拖动：松手提交一次定位，成功后继续；不在每次手势更新重建音频会话。
- C219 跨音频片段定位：按真实帧范围、timebase 与 priming 映射，不能将单文件进度当整条录音进度。
- C220 部分范围原音缺失：波形标记断点或不可用区，禁止定位到缺失范围，不伪装成连续完整原音。
- C221 持续接收时稳定范围：播放使用稳定的已收范围，新片段不在拖动时改变时间尺；明确刷新或结束后纳入。
- C222 列表迷你播放器：有播放或暂停目标时才显示，点主体回详情，暂停及结束按钮不误触导航；列表底部留空间。
- C223 切换回放目标：整条录音与引用片段共用控制器，终止旧目标；失败不残留旧播放态，迟到回调不串入。
- C224 引用片段播放边界：显示片段内时间和真实来源范围，结束不越界播放其他录音，可明确打开完整录音。
- C225 原音播放结束：进度停在目标结尾，恢复播放语义；再次播放从该目标开头开始，不自动切别的录音。
- C226 系统打断与耳机断开：停止活跃播放并保留可恢复位置，系统恢复后不自动发声，需用户明确续播。
- C227 真实音频波形：用实际音频包络并缓存，长录音有界处理，不复用手表装饰波形或随机动画。
- C228 总时长未知：显示未知总时长并暂不支持比例拖动，真实播放暂停仍可用，不伪造完整进度。
- C229 定位准备或恢复失败：错误出现在播放器位置，保留最后有效位置，旧目标或被删除音频不能被迟到任务复活。
- C230 播放器可访问性：进度为可调控件，播报当前和总时长；44pt 命中、大字号与减少动态效果下可操作。

## 流式呈现与阅读

- C198 首字前停止：等待期间也可停止；保留原问题，恢复发送。
- C199 网络到达与显示节奏分离：模拟分包到达，显示只处理新增尾部；目标缓冲不作为网络延迟承诺。
- C200 突发大块数据：适度加快显示排空，不让用户等待整篇逐字动画。
- C201 长间歇与无首字：轻量等待，不伪造百分比；超时恢复路径需原生实施时验证。
- C202 停止保留收到的内容：停止时显示已接收但未播完的尾部；不显示可见的已停止文字，只播报一次读屏状态；后续回调不得继续追加。
- C203 停止后马上发送：保留旧的部分回复，新消息启动独立任务；旧回调不能串入。
- C204 中断重试不重复问题：保留部分回复至用户主动重试，重新生成复用原问题；本稿重试替换当前回答。
- C205 向上阅读不强制跟随：用户离开底部后，新片段和完成事件都不把页面拉回底部。
- C206 回到最新恢复跟随：点击入口滚动至最新内容；接着跟随新增文字。
- C207 组合 emoji 与重音字符：按 grapheme 分段，家人 emoji、肤色、变音符不拆开动画。
- C208 稳定的已完成 Markdown 块：已完成段落保留 DOM；仅尾部更新，未闭合块以纯文本等待闭合。
- C209 代码与表格横向滚动：溢出在各自容器内滚动，不能撑宽整段对话或手机视图。
- C210 流式中选择文字：不替换用户正在选择的正文块；复制当前已显示内容。
- C211 输入中换行与中文输入法：Shift+Enter 换行；组合输入时 Enter 不误发；输入区最多六行。
- C212 生成时继续编辑草稿：允许编辑下一条消息，停止操作不清空新草稿；繁忙时 Enter 不另开并发回复。
- C213 页面退出清理演示：历史演示离页时清理模拟计时器；原生页面退出只清理展示订阅，跨页任务归运行时管理，返回不重复启动或串入其他会话。
- C214 回复状态读屏播报：开始、完成、停止、中断各播报一次；不逐字打断读屏。
