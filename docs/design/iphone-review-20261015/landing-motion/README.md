# MoMoAgent · Personal Agent landing v5

Run `node server.mjs`, then open http://127.0.0.1:5149/preview.html . The server binds only to localhost. Rebuild with `node build-preview.mjs` after replacing the Pen HTML export.

Three future scenarios show existing life context: travel, work follow-up and a family birthday. Entry appears after all three; replay resets the gate. One existing procedural Avatar moves into the home preview, and the original brand icon moves into the navigation bar.

This is an illustrative design preview. It does not record audio, create memories, send messages or perform bookings. The actual native introduction lives in Apps/iPhoneApp/Bootstrap/PhoneWelcomeView.swift.

`motion-checks-v5.json` records the full story, early-entry gate, dark mode and reduced-motion 320px checks. `public-check-v5.json` records the HTTPS tunnel end-to-end check. Original Avatar provenance and licensing are retained in AVATAR-SOURCE.md and AVATAR-LICENSE.txt.
