# MoMo Agent 设置层级整理 · 2026-10-27

本轮保持 2026-10-22 Mac Typeless 与手机 MoMoPalette 视觉基线。采用 standard 强度，不增加动效、徽章或桌面卡片。

比较了继续使用“高级”中转、将全部设置铺成单页、按用户任务聚合三种结构。选择任务聚合：Mac 依靠原四项侧栏；手机依靠三组列表。复杂输入保留独立页面，单纯状态取消中转。

## 导航与交互

- Mac：模型 / 设备 / 记忆 / 通用。设备页同时管理配对设备、远程访问、网络状态与当前地址；点击连接方式在右侧原地进入子页，右上角返回设备页。配对和撤销沿用原流程与确认。
- 模型：当前服务、模型和运行状态继续使用开放行；选择服务也使用行，不在日常设置中重复 onboarding 大按钮。停止运行仍是修改模型前的明确操作，不影响聊天页的自然任务交互约定。
- 通用：电脑控制（权限、交还控制）与运行环境（运行组件、结果文件夹）；权限继续使用独立原生引导窗口，不改权限申请与拖放机制。
- 手机：MoMo（Mac 连接、记忆、通知）、个人资料（健康、到访地点、日历、提醒事项）、转录与储存（模型、语言、语音检测、储存空间）。从设置一跳进入各页，删除“高级设置”中转。
- Mac 连接页直接显示配对、连接与网络状态；手动输入保留独立页面。鉴权失效时只出现一个重新配对入口。
- 记忆：保留原文、来源和分页语义；刷新放在工具栏，录音投递/整理状态原地展开，删除放在各记忆的菜单并保留确认。导航返回不再叠加“完成”。
- 资料授权仍明确采集范围、向 Mac 同步、AI 使用与撤回后的保留边界。开关由原同步对象持有；错误和重试留在所属页面。

## 视觉与状态所有权

Mac 保留 #F3F3F3 侧栏、#FAFAFA 连续画布、22pt 标题、14pt 行和 36pt 胶囊操作。手机复用原 20pt 圆角、58pt 行、18pt 内边距及 palette；当前 main 尚无独立 PhoneSettingsChrome 文件，本次将这些既有值提取为共用组件。系统导航和工具栏保留原质感。

2026-10-28 顶部契约：两栏背景从窗口 y=0 连续到底，原生红绿灯直接浮在灰色侧栏上，不另铺横跨全宽的标题栏底色。侧栏“设置”顶部为 48pt；切换 tab 与关闭重开都不得恢复系统标题或背景白条。实机修复与像素证据见 [顶部背景验证](../implementation/settings-titlebar-20261028.md)。

持续任务、配对和来源授权仍归运行时所有；页面仅拥有当前面板、展开和确认状态。没有新动画，减少动态效果下沿用原生过渡和记忆列表后备；没有新增透明材质。默认字号验证。

Pen：`momoagent-mac.pen` 中更新 IKzlQ（设备）、BHDzq（通用）及相关侧栏，新增 BVdd0（手机完整滚动内容）、TdqIh（Mac 连接）、kA0IU（记忆）。画板数据为合成样例。

## Typeless 2.9.0 bundle 复核

2026-10-27 从 [官方 Apple Silicon 入口](https://www.typeless.com/desktop/mac-apple-silicon/download) 下载 `Typeless-2.9.0-arm64.dmg`，校验 DMG 后只读挂载；没有安装、启动或执行 bundle 脚本。`app.asar` SHA-256：`2972d105bba9bd66ee0f71ccda8c40c3a00eff5a0590b0c70cf45d9aa99e4568`。只解析 ASAR 的 JSON 索引并读出 JS/MJS/CSS；源码与资源不纳入产品。

实际组件位于 `dist/renderer/static/js/BDDWOLEx.mjs`：

| 组件 | 真实实现 | MoMo 的原生映射 |
| --- | --- | --- |

| `P5` 文本 | 标题 14/20、500；说明 14/20、400、tertiary；二者 gap 6px | 14pt medium 标题；保留原 12pt 状态/元数据，间距 6pt |
| `Na` 组头 | 16/24 medium、tertiary；底部 16px + 细分隔，下一行间距 4px | 保留既有克制的小组头与开放画布，不新增卡片 |
| `Px1` switch | 30×18，thumb 14，右栏收紧；disabled 与 focus 有独立状态 | 原生 switch + labelsHidden，放在最右侧，保留可访问性标签 |

`DGFxDefo.js` light palette：主文字 rgba(17,17,17,1)，次文字 0.75，tertiary 0.55；薄边框 rgba(119,119,119,0.07)，主/上层白色，下层 rgba(242,241,240,1)。这些用于核对层级；MoMo 仍保留 #F3F3F3 / #FAFAFA 与现有 MoMoPalette。

远程访问状态归入标题下方，不单独占“状态”行。地址、模型只读值右对齐且允许换行选择。连接方式日常管理不再复用 onboarding 卡片、大 logo 或“继续”按钮；登录/保存为右侧 36pt 胶囊。自建服务器保留说明、设置帮助、验证和重新配对提醒。
