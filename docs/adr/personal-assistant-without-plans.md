# 私人助理直接回答与计划功能退役

2026-10-15，用户明确要求回复直接谈事情，去掉查录音的过程叙述，并完全取消计划功能。本决定覆盖旧方案中的计划要求。

## 行为与边界

系统提示统一维护在 MoMoAgent 的 AgentInstructions。默认直接回答事情本身，已有资料足够时不用工具，补充检索安静执行。取消逐项说明查阅过程、强制短引原句和固定报告结构；具体事实保留紧凑数字来源链接，关键歧义自然说明。保留真实来源、转写不确定性、请求时钟、提示注入防护和回听授权，不再把旧验收失败案例塞入生产提示。

不对模型回复做关键词删除或前端改写。独立渲染器仍接收真实文本、工具与状态；前端不承担 Agent 决策。工具注册由六项减少到五项，不再提供 write_plan，也不再在请求恢复时检查计划提交。旧历史里出现该名称不能恢复能力：真实 Pi 回归测试请求旧工具，验证被拒绝且没有新建文档。

手机删除计划列表、详情、编辑器、导航和缓存加载，移除相关错误提示及旧工具展示标签。资料、聊天、来源回听和设置继续使用原有边界。

## 旧资料与验证范围

不删除用户已有计划文件或数据库记录。Archive 内保留旧格式、迁移、投影恢复和来源删除后的清理代码，防止升级丢失数据、破坏旧库或绕过原有隐私清理。它们不向 App 或 Agent 暴露计划入口，也不向模型注入计划内容。Archive 兼容层的历史测试继续保留。

删除退役功能的 UI 用例。当前 Agent、真实 API/UI 验收场景改成回答问题、检查来源及无新增计划；HTTP 工具分片改用当前只读搜索，取消后仍校验没有工具成功执行。J20 的计划写入强杀场景退役，J21/J23 仅以旧 Archive 文件为兼容夹具，不再让 Agent 创建计划。旧 AgentQuality JSON 语料和旧证据保留历史含义，不可直接用于本版计划验收；当前 Swift 开发集改为自然问句与回答检查。

本次本地自动测试证明注册、传递、持久化、导航与渲染行为，不能证明真实模型已经具备满意的说话方式。付费 API 场景为显式运行入口，不自动发起请求；真实模型的事实支持与语气仍需单独复核。
