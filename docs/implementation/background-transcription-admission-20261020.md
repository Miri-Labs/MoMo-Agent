# 后台整理接收尚未分析的原音

“后台继续整理”按尚未处理的已接收原音显示，但原入口只冻结已完成语音检测、尚未领取的识别窗口。原音尚未分析，或唯一的窗口正在识别时，入口会返回空批次，并显示“目前没有已准备好的待转录片段”。

## 修改

- 用户点击时，先取消并作废当前自动领取的工作，再冻结本机已有的待处理范围。交接只等待数据库操作，不等待原生模型返回；原生读取结束后才释放音频租约。
- 批次复用现有持久化范围表，同时保留待识别窗口和未分析原音。后台依次执行语音检测、窗口登记和识别。显式申请可以重试处于自动退避期的分析。
- 分母固定为申请时的范围。后续收件进入自动队列；语音检测使用已接收快照边界，不伪造录制结束事件。纯静音按实际分析结果计入完成。
- 暂停批次同时保留分析范围。结束执行会作废该批次的分析尝试，迟到结果不能提交。完成前核对全部冻结范围；删除计入移除量，缺失或失败不计入已转写。
- 点击时工作已完成属于正常空队列，刷新状态后返回，移除原来的错误提示。

版本：1.15.1，内部构建号 73。

## 验证

在 Mac 上使用实际 SQLite 数据库执行 Archive 的 216 项测试，全部通过。新增测试覆盖未分析原音入队、固定分母、后续收件、接收缺口、纯静音、删除、暂停后重开、过期结果、分析退避重试和批次范围校验。

使用 App 协调器原文件、实际 Silero/SenseVoice 模型及官方中文音频执行 14 项集成测试，全部通过。新增两项分别验证未结束录音从原音开始完成后台批次，以及正在识别的唯一窗口交接。其余用例覆盖系统到期、前后台切换、用户暂停、并发停止和音频租约释放。Mac 测试只替换资源路径与 XCTest 附件输出，不替换模型或协调器实现。

四语言目录、占位符和原生文本覆盖检查通过。测试日志与 Mac 测试副本保存在本轮 `tmp_agent_output/20261020-background-admission/`。

这些结果验证数据处理与任务生命周期；iOS 对持续后台请求的实际授予及设备切后台后的运行，需要在手机上单独验收。
