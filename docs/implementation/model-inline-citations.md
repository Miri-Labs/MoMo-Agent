# 模型生成行内原文引用

更新：2026-10-15。

此前聊天把整个会话读过的 `sources` 追加为“参考原文”，计划页也自动罗列 `plan.sources`。读过资料并不表示当前回答采用了它，因此这些列表不能作为模型引用。

聊天正文和计划正文现在统一使用 Markdown 行内引用，例如 `周五讨论方案。[录音1](momoagent://source/SESSION_UUID/SPAN_UUID?version=2&generation=3)`。模型决定引用哪个段落及引用位置，客户端复用 Foundation Markdown 和现有原文链接解析器，不自动补引用、编号或参考列表。

- 近期上下文、搜索与分段读取的每条 passage 都提供准确的 `citationURL`。旧持久上下文缺少这个新增字段时仍可解码；原有结构化来源字段保留。
- 提示词和 `write_plan` 工具要求在所支持的事实旁引用，计划的 `sources` 只记录正文实际采用的来源。未使用原文的建议不伪造引用。
- 会话级 `sources` 继续作为已读资料的授权与失效登记，不改为引用列表，避免丢掉修订或删除后的上下文清理屏障。
- 点击链接仍校验 session、span、version 和 generation，并通过档案的实时版本检查打开原文与回放。无效或过期引用不跳到其他来源；错误提示不再指向已删除的底部列表。
- 历史正文与原始 Markdown 不重写，也不根据旧元数据臆造行内引用。录音标记是用户的手动定位入口，保留为“查看标记附近的转写”，与模型引用分开。

付费 Agent UI 用例已改为点击正文原生链接并实际核对原文，明确拒绝以旧“原文 1”按钮代替模型引用。普通验证不自动调用付费模型。
