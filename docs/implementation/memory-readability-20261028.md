# MoMo Agent 记忆阅读修复（1.38.1）

Hermes StarMap 原浮层把整条记忆作为黑底粗体标题，换行只按空格处理，中文和 UUID 长串会超出窗口；缺少来源日期时又显示 `unknown memory`。

本次保留上游星图、布局和原生记忆存储，通过现有构建适配层替换浮层：

- 最大 420 px 阅读卡片，15 px 常规正文、24 px 行距，按 Unicode 字素换行；最多六行预览，超出时明确显示省略号和全文入口。
- 来源类型、可确认的日期独立显示，缺少日期不补造。仅识别旧录音的精确 UUID / 版本前缀用于预览分层；归属未确认等限定保留，详情仍显示原始全文，原生 ID、记忆文件和 API 数据不变。
- 点击节点、预览卡片或右键均打开原生全文阅读器；支持选择文字。卡片避开时间轴与图例，窄窗口隐藏重复操作说明。
- 手机和 Mac 共用的全文组件将类型放在正文前，增加段内行距，保留全部来源证据。

验证：`npm test --prefix Apps/MacApp/MemoryUI` 六项通过，覆盖无空格中文、长 ID、组合字符、段落、来源限定、原文/ID 保留、窄窗口边界、显式截断与卡片命中。`npm run build --prefix Apps/MacApp/MemoryUI` 成功，随包离线资源已更新。XcodeGen 2.46.0 校验后 Mac Release 构建成功；生成器仅产生无语义的拷贝阶段排序，未保留该噪声。

浏览器使用构造记忆验证浅色 1000×640、深色 320×400；节点和卡片点击返回同一原生 ID；窄窗口未再覆盖时间轴，长正文可经全文入口访问。截图保存在本机 `outputs/memory-qa-light.png`、`outputs/memory-qa-dark-narrow.png`。原生安装验收单独记录，不将浏览器事件回执冒充原生阅读器验收。

正式 Mac 已覆盖更新到 1.38.1，签名 designated requirement 与原安装一致。实际点击截图对应的记忆节点，原生阅读器显示同一条完整记录；关闭后显示新版阅读卡片，列表切换正常，时间轴键盘 Home/End 分别为 0/100。模型页已核对“MoMo 正在运行”，记忆页保留七条原生记忆和原 Dream 时间。更新时没有活跃 admission；首次冻结运行目录遗漏上游清单导致启动失败，补齐 `Vendor/HermesAgent.UPSTREAM.json` 后重启验收成功。未改系统权限或用户数据。本次未重新安装手机和手表，共用正文排版随下次手机更新交付。
