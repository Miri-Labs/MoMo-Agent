# iPhone v8 设计实施

本轮按 [v8 交接](../design/iphone-review-20261015/HANDOFF.md)、用户确认的 [播放器补充](../design/iphone-review-20261015/AUDIO_PLAYER.md)，以及实施期间的首页光学位置、专属头像和手表状态反馈完成代码。设计包从用户指定的 initial-implementation 工作区复制，原工作区未提交改动保留。任务分支 `codex/iphone-v8-implementation` 起于 main `832c9dc`，已合入随后更新的 main `2d70596`，保留个性与记忆功能；也合入 `0f83f2f` 的发布草案。最新代码提交为 `aed2c1f`，最终证据文档单独提交。

220 个设计场景是预期行为清单，不能把下列定向测试称为 220 项全部验收。Watch 界面、固定本地语音模型、模块边界和旧计划数据继续保留；本轮没有执行收费服务调用。

## 已实现的行为

- iPhone 使用独立的中性浅/深色语义颜色、系统字体、统一正文和标题层级、Dynamic Type。首页品牌、问候与输入保持水平居中，按可用高度整体上移到光学中心；键盘和大字号重新布局。原始产品图标原样保留。
- 手表状态收进首页导航标题：品牌下方用 Apple Watch 图标与 13pt 真实状态文字，不再占独立横幅。整组可点击进入转录；大字号优先展示状态，完整品牌与状态保留于读屏标签。没有新增虚构在线状态或百分比。
- 左侧覆盖抽屉支持历史选择、标题搜索、草稿保留与单飞新聊天。底层导航在抽屉打开时不接收触摸，遮罩和抽屉明确排序，搜索按钮命中区域为 44pt。无模型配置也能创建和重新打开纯本地空讨论；首次发送才加载 SDK。已有持久聊天不会被替换成空白快照，存储失败保留原会话与草稿。
- 服务设置采用同一套名称、HTTPS 地址、协议、密钥和模型字段，支持多连接与独立 Keychain 引用。预设只填通用值；模型目录不可读仍可手填，再以真实工具能力探测验证并应用。草稿修订、票据过期、取消和迟到结果按身份隔离；目录权限错误不误判推理权限。离开连接页或高级设置会释放文本焦点，返回后操作不被旧键盘遮挡。
- 聊天按稳定 Markdown 块更新，只淡入新尾部；上滑阅读不抢底部。停止立即展示收到的尾部，只播报一次，不显示可见“已停止”。精确复制和重新生成绑定指定回答及原问题；行内引用仍通过来源版本、代次和授权校验。合入 main 的记忆工具继续用对应的读取/更新展示。
- 转录按全库分页搜索、真实状态和正文展示；原音保留和容量来自实际资料。失败重试限定录音和代次，不重复已完成窗口。
- 详情主播放器、列表迷你条和引用片段共用一个原生音频控制器。暂停保留逻辑位置，续播、定位和原音验证使用真实 AVAudioPlayer / 文件帧；片段严格限制引用范围。波形来自实际 PCM 包络，静音与缺口保留，不生成装饰波形。音频中断、路由变化和失效按真实状态暂停或拒绝。
- 删除会停止失效的播放目标；关闭操作等待已在途的原生清理与波形读取释放租约，并发关闭也能等待同一清理。取消的触摸手势会结束手动滚动状态，不永久阻断后续跟随。

## 专属头像

等待态和思考过程中的 `✳` 已移除。按用户追加指令，实际接入 [Bible Strong Avatar Lab](https://github.com/smontlouis/bible-strong-avatar-lab) 的程序化几何和浏览器运行时代码，固定提交 `79fe9ba06e4874b11394b8e8a3f2c493c9d197ba`。最终造型由我们手写的参数定义：圆角主体、两个高低不同的短声波和简单双眼，非圆形、非上游预设角色。首页图标未替换。

动画使用上游的投影、环境运动、姿态过渡和眨眼逻辑；轻微转动、偶尔眨眼，最多 24 次绘制/秒。停止、隐藏、Reduce Motion 和销毁会取消所有帧、步骤与眨眼调度，静态过程图不启动动画。全部代码离线打包，不嵌入 Studio、React、分析 SDK 或远程头像页面，原 WKWebView CSP 保持。先前的手写 SVG 版本只属于历史构建，最终使用真实上游引擎。

原始源码、完整 AGPL 许可证、24 个固定文件的 SHA-256、明确补丁和可重建脚本见 [Vendor/BibleStrongAvatar](../../Vendor/BibleStrongAvatar/README.md)。应用包内保留完整许可。Pen P26 与 [静态 SVG](../design/iphone-review-20261015/icons/momoagent-listening.svg) 已同步最终代码生成的姿态；正式 App 使用运行时，不使用静态 SVG 播放动画。分发合并应用时仍需处理上游许可义务。

hosted03 额外暴露两处不同问题：删除后的原生清理已摘除引用，但并发关闭未等待在途释放，现由共享清理任务处理并以阻塞 deactivation 的真实门控复验；独立 WK 测试没有采用正式页面的 `.never` 内容安全区策略，现已对齐并保存有界滚动事件诊断。新发现的 `touchcancel` 漏复位单独修复，不将它冒充纯 JS 点击失败的原因。

UI05/06 对系统密码保存窗口的“绝不出现”断言超出了公开 API 保证，也不是交接要求。Apple 的 [Password AutoFill 说明](https://developer.apple.com/videos/play/wwdc2018/204/) 表明系统会根据输入与页面移除推断登录；[Return delegate](https://developer.apple.com/documentation/uikit/uitextfielddelegate/textfieldshouldreturn(_:)) 只能阻止 Return 默认处理，不能承诺关闭这类推断。最终测试验证用户拒绝可选系统保存后流程正常，不保存测试密钥，不更改设备 AutoFill 设置；不声称 App 能禁止用户自行把密钥存入密码管理器。

静态 UI 检查的高优先级提示经逐项审阅：UUID 用于持久任务身份，TimelineView 用于可暂停的绘制时钟；迭代项使用稳定业务身份，固定图形保留至少 44pt 点击区。手势取消后的定位预览复位已在最终播放器 UI 旅程通过。该脚本是启发式辅助，不将其输出数量当成自动可访问性验收。

## 验收边界

本轮不宣称完整 v0.1 发布、220 个场景全覆盖、真机录音/后台/续航、WatchConnectivity、真实来电或蓝牙路由已验收。头像静态截图不能证明动画，受控可见性测试不能替代物理设备后台行为。中文 ASR 的“开饭时间”已知识别错误保持开放，未篡改原稿或当成纠正后的事实。真实服务商能力和回答质量需要各自授权的在线复验；本轮没有用合成响应代替这些结论。
