# 回复完成后的过程收起

用户要求回答完成后将思考过程与工具调用收起。本轮保留执行中的独立步骤与鹅卵石动效，将完成后的每段连续过程合并为一条原生 `details` 摘要，保留过程与正文的顺序。

摘要显示操作完成数、失败、中断、结果待核对或未确认完成。回复结束时自动收起一次；用户之后展开的过程和工具详情，在重复快照、后台恢复或新一轮回复中保持展开。重新加载历史默认收起。点击摘要一次就能读到思考内容；工具详情保留独立的展开入口和执行 ID。日程、提醒、闹钟等已落库的实际行动结果卡继续在摘要外显示，仍可查看和修改。

工具消息结束与整轮回复结束分别处理：工具执行后等待下一次模型返回时保留进展展示，正文仍在流式输出时保留用户选择；可见正文完成、停止、失败或达到长度上限后才统一收起。只有当前轮驱动活动状态。收起发生在用户阅读正文期间时，按实际可见的正文块补偿滚动位置；只在完成转换时测量布局，不在每个 token 更新时测量。
