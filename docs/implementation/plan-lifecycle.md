# 手机计划的编辑与删除

计划页支持手动新建、编辑、保存和删除。Agent 生成的计划使用同一份本机档案。编辑保留来源引用；用户删除计划时，录音和转录继续保留。

SQLite 是计划正文与版本的真源，Markdown 保存在 `Documents/workspace/plans/<plan-id>.md`。计划增加 `revision` 与 `updatedAt`；旧文档按第 1 版读取。打开编辑页时保存一份草稿和对应版本。保存、删除都检查该版本，旧编辑页不能覆盖另一份已保存的修改。

Agent 创建计划时的 `operationID` 和原始输入哈希保持不变。用户编辑后，原操作重试返回当前计划。用户删除后，数据库清空正文和来源关系，仅保留阻止重复创建所需的操作记录。相同 Agent 操作重试不能恢复已删除的计划。

保存先提交数据库，再替换 Markdown。数据库保留上一份投影的哈希；如果进程在两步之间退出，重启后只在文件仍是上一版或当前版时完成投影。在“文件”中修改或删除计划稿件会触发冲突，App 不自动覆盖它。符号链接路径拒绝读取、替换和删除。稿件读取有大小上限。

正文来源被修改或删除时，继续使用既有来源失效机制。已经打开的计划草稿不能恢复旧来源。编辑页保留草稿并提示冲突，便于复制内容。

回归入口：

- `MoMoArchiveTests/PlanLifecycleTests.swift`：真实 SQLite 与文件，覆盖版本冲突、操作重试、删除、来源失效、外部文件修改、投影中断与旧格式读取。
- `PhonePlanJourneyTests`：在无模型密钥的 iPhone 模拟器中，新建、编辑、重启、删除并再次重启。

本页描述实现契约。测试的实际执行结果见[实施记录](status.md)。后台转写入口、原音导出和设置页容量诊断属于其他工作项，不由计划页实现完成情况替代。
