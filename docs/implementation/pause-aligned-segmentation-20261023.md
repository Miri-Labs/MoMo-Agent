# 沿短停顿切分长语音

历史记录：下文描述 1.19.12。1.19.13 已移除这项优先规则和能量统计，当前实现见[移除短停顿优先切段](bounded-speech-segmentation-20261023.md)。本页保留当时的实现与对照结果；对应源码保存在提交 `f01601a6`。

版本 1.19.12 保持 20 秒核心窗口上限，超过上限时优先在第 15～20 秒内寻找短停顿。没有合适切点时仍在 20 秒切开。语句首尾的 300 毫秒保留、跨窗口最多各 1 秒的上下文、原始音频和正文归属规则继续使用。

本次改动只影响新处理的归档录音。已完成的历史分析沿用原结果，不触发历史重跑。输入框语音识别继续走原有独立路径。

## 实现与取舍

`SpeechPauseProfile` 随现有音频读取器消费已经解码的 PCM，每 20 毫秒保存一个均方能量值。规划器在 Silero 已选出的语音范围内寻找至少 160 毫秒的能量低谷，选择搜索区间内最后一个合格低谷的中点。低谷能量须低于当前核心窗口能量第 75 百分位的 4%；这个相对值会随录音音量变化。平坦噪声和全零输入没有相对低谷，不会自行生成候选。

这些数值是当前的保守切点参数，需要更多正常佩戴录音校准。它们不用于决定有没有语音，也不扩大 Silero 选择的范围。低谷也可能对应轻声或清辅音，因此相邻窗口仍保留上下文，覆盖的音频样本不因切点移动而减少。

上一轮[切段研究](segmentation-study-20261023.md)提出读取同一次 Silero 推理的逐帧概率。核对后，当前固定 sherpa C API 只暴露结束片段和带滞后的说话状态，没有概率读取接口。本次采用已解码 PCM 的能量低谷，仅提供切点提示，避免为这项功能新增原生推理接口。没有第二次 VAD、ASR 补检、额外文件扫描或新模型。仍使用现有 sherpa-onnx / Core ML 及原始权重。

单个两分钟调度任务产生约 48 KB 的有效能量值，数组扩容会预留额外容量；每次排序至多处理约 1,000 个能量值。分析完成后这些值释放，不进入数据库，也不留在跨任务的 VAD 状态中。末尾不足 20 毫秒的样本仍参与原有音频分析和覆盖，只不用于生成低谷提示。候选至少在核心开始后 15 秒，避免按每次呼吸拆成小窗口。

切段版本标识改为 `silero6-pause-aligned-v4`。迁移依次携带 `silero6-speech-only-v3`、`silero6-selective-archive-v2`、`silero6-complete-coverage-v1` 及旧版已完成结果。

## 对照与验证

使用 sherpa 官方公开中文样本“开放时间早上9点至下午5点”，重复 24 次，每次间隔 300 毫秒，共 141.108 秒。另生成一份固定随机种子的低幅非零背景噪声版本。使用手机默认 VAD 阈值 0.25。参考文字保留原文，不把模型输出中的“开饭”替换为“开放”。

对照共享同一次 VAD 检出的范围，用旧的固定 20 秒规则重新规划窗口，再使用相同模型分别识别。以下输入时长包含上下文，来自窗口范围；字符错误为去除标点后的 Levenshtein 距离。

| 场景 | 切法 | 字符错误 / 参考字符 | 输出字符 | 窗口数 | 含上下文输入 |
| --- | --- | ---: | ---: | ---: | ---: |
| 原始公开语音加短停顿 | 固定 20 秒 | 0 / 312 | 312 | 8 | 154.348 秒 |
| 同上 | 自动沿低谷切分 | 0 / 312 | 312 | 8 | 154.674 秒 |
| 加非零背景噪声 | 固定 20 秒 | 6 / 312 | 308 | 8 | 154.348 秒 |
| 同上 | 自动沿低谷切分 | 1 / 312 | 312 | 8 | 154.674 秒 |

窗口坐标、源码校验值和测试组结果见[验证记录](evidence/pause-aligned-20261023/results.json)。

新切法的输入增加 0.326 秒，约 0.21%。原因是旧切法留下不足一秒的尾段，部分上下文被范围边缘截短；移动切点后恢复了这部分上下文。两种方案的核心覆盖范围完全相同。带噪声的新结果仍有一处同音替换，不能称为全对；测试保留这项明确误差上限，并要求比旧切法更少错误。

这组证据只说明该公开素材上的结构变化。它使用同一句话重复构造，不是多人日常对话准确率。识别在 Mac 的 sherpa CPU 上执行，不能据此推导手机 Core ML 的小时处理耗时、发热或电量。

相关回归覆盖：

- 不同读取块大小和录音音量下，候选切点一致；40 毫秒低谷不会替代合格短停顿。
- 有停顿、无停顿、短句、非零噪声、数字静音、核心覆盖和上下文上限。
- 跨物理文件、跨两分钟调度任务、取消后重启、连续录音未结束时的处理。
- VAD 时钟滚动、44.1 / 48 kHz 重采样连续性、非有限采样拒绝和诊断计数。
- 已完成正文和无语音覆盖迁移，不重复处理历史。

自动切点和公开模型对照在 `CompleteCoverageTests.swift`；调度恢复在 `CompleteRecordingTests.swift`；历史保留在 `AnalysisUpgradeTests.swift`。测试没有读取手机历史资料。三个测试组通过；需要私有历史样本的诊断项未启用。

iPhone 与内嵌手表、手表小组件的未签名 Release 构建成功。`verify-release-bundle.py` 的 29 项检查通过，三个包均为 1.19.12。此次完成代码和构建验证，尚未安装到设备。

## 上游与复现

[Silero 官方切段实现](https://github.com/snakers4/silero-vad/blob/master/src/silero_vad/utils_vad.py)在到达长度上限时寻找短停顿。这里采用其“先找停顿、再按上限切开”的思路；能量候选的实现与阈值属于 MoMoAgent，不能视为 Silero 概率。

[sherpa 1.13.8 C API](https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.8/sherpa-onnx/c-api/c-api.h)是本次接口核对依据。运行公开模型测试时，将 `MOMO_SPEECH_MODEL_DIRECTORY` 指向通过仓库模型清单校验、包含官方 `test_wavs/zh.wav` 的目录，运行 `CompleteCoverage`、`CompleteRecording`、`RealSpeechTests`、`AnalysisUpgrade` 和相关流式及诊断测试。`PAUSE_COMPARISON` 输出两种切法的字符错误与输入范围，`PAUSE_EVIDENCE` 输出自动切点。
