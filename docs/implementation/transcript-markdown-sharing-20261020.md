# 按日期和时间段分享转录

转录页右上角显示系统分享图标和「分享」。点击后默认选择当前浏览的日期，也可选择「自选时间段」，填写开始和结束日期、时间。再次点击「分享」生成一个 `.md` 文件，并打开 Apple 原生分享面板。用户在系统面板中选择 AirDrop、邮件或其他支持文件的目标。

## 文件内容与范围

- 当天分享使用录音时的本地日期，与转录时间线的归组一致。
- 自选时间段使用手机日期选择器对应的绝对时间，可以跨天。选择规则为 `开始时间 <= 段落起始时间 < 结束时间`，保留完整段落。
- 原文和手表标记按时间从早到晚排列，时间戳包含录音时的 UTC 偏移。正文中的 Markdown 和 HTML 字符经过转义，以保留原意。
- 文件只包含分享时已有的文字、范围说明、生成时间和标记。录音仍在继续、转录尚未完成或原音已经清理，都不阻止分享现有文字。
- 当天文件名如 `2026-10-20.md`，自选范围文件名如 `2026-10-19_23-30_2026-10-20_01-00.md`。没有文字时显示「这个时间范围还没有可分享的文字。」

分享不会触发转录、总结、同步或模型调用。读取只在点击分享后执行，不随转录页刷新而重复生成文件。跨天读取在日期之间让出执行机会，允许接收录音和转录任务继续访问资料库。

## 文件生命周期

复用 `ArchiveExportController` 和 `ArchiveShareSheet`。`ArchiveExport` 增加时间线来源类型，原单次录音导出继续使用已有校验。

在交给系统之前，核对来源是否被修改或删除。分享使用冻结的临时副本，文件在 `UIActivityViewController` 的完成回调后清理。单纯关闭 SwiftUI 分享面板不提前删除文件，因为目标扩展可能仍在读取。取消准备会清理已生成的副本；清理失败允许重试，冷启动继续沿用遗留副本清理。
