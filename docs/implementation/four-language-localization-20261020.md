# 首批多语言适配

本轮从 `origin/main` 的 `bab6784` 开始，交付前合入 `2ef6209` 的 VAD 连续性修复，交付版本为 **1.15.0**。首批覆盖简体中文界面及普通话识别、英语、日语、韩语。手机、手表和手表小组件共用本地语言资源。

## 用户如何选择

- iPhone 界面使用系统为 MoMoAgent 选择的语言，应用内不展示界面语言设置或说明卡片。
- Watch 界面跟随手表为应用解析出的语言，“更多”不展示界面语言。两端可以使用不同语言。
- 录音识别与界面语言分别设置。默认自动识别；手机高级设置可指定普通话、英语、日语或韩语。原有粤语识别选项继续保留。
- 手表采集原音，手机执行现有 SenseVoice 本地转写。语言适配没有增加录音传输频率，也没有增加并行识别模型。
- 不支持的系统语言回退到英语。中文地区或繁体偏好在首批使用简体中文界面。

## 覆盖内容

原生页面、录音与同步状态、错误说明、回听、时间线、设置、附件、VoiceOver 标签及系统权限用途说明均使用四语言资源。聊天网页中的思考状态、工具调用、闹钟/待办/日程卡片、按钮与无障碍说明使用同一资源生成的字典。日期及星期列表按当前界面语言格式化，保留事件原有时区。

聊天回复优先遵循用户当前消息或明确指定的语言。用户消息未明确表达语言时，使用应用语言。引用、姓名、代码、网址、录音原文和用户自行填写的事项标题保持原样。转录总结跟随原文的主要语言；混合语言保留专名。

新建或重置助理身份时，使用对应语言的默认性格模板。已有自定义身份文件保持不变。后台新增记忆使用应用语言或用户明确偏好的语言；切换界面语言不触发既有记忆翻译。首页建议缓存包含语言字段，切换语言后可重新生成；旧缓存仍可解码。

既有转录、聊天、记忆和资料标识保持不变，不因界面语言切换重转写历史。同步状态仍由原有状态机管理；可重试判断使用状态枚举，不比较翻译后的文字。

## 资源与维护

`Packages/MoMoAgentKit/Sources/MoMoContracts/Resources/Localizable.xcstrings` 是共享文案来源，包含四语言译文。原生应用及 Swift Package 均处理这份资源。两个应用各自的 `InfoPlist.xcstrings` 提供权限用途说明。

原生 SwiftUI 字面量由系统本地化。动态字符串使用 `String(localized:)`；包内字符串指定 `AppLanguage.resourceBundle`。`AppLanguage.current` 在进程内解析一次，不在流式消息或录音电平更新时反复解析。

维护原生插值键时，检查编译生成的 `.stringsdata` 中的实际参数类型。例如整数插值可能是 `%lld`，不能仅添加 `%@` 键。译文必须保留各参数及类型；参数顺序调整时使用位置参数。

聊天使用的词条具有 `Chat renderer UI` 注释。修改共享词条后执行：

```sh
uv run Tests/Support/sync-chat-localization.py --write
uv run Tests/Support/check-localization.py
uv run Tests/Support/sync-chat-localization.py
# 完成原生构建后，再核对编译器实际生成的键。
uv run Tests/Support/check-localization.py --compiled-directory <本任务的DerivedData目录>
node Tests/Support/chat-renderer-core.test.cjs
node Tests/Support/chat-localization.test.cjs
```

聊天字典只在渲染端本地读取，不产生翻译请求、额外定时器或模型任务。业务枚举原始值、数据格式、正则表达式及给模型的资料协议不通过界面翻译表改写。

## 验证边界

自动化覆盖语言解析与回退、四语言资源、插值参数、原文保留、聊天工具/卡片、默认性格文件及旧建议缓存兼容性。原有转录、录音和归档测试继续运行。双端原生构建验证资源可被手机、手表和小组件编译打包。

本轮的分层结果：

- 合入最新 main 后，352 项 Swift 包回归通过，包含四种语言默认性格文件的检查。
- 聊天渲染器原有 19 项检查及四语言工具/卡片检查通过。
- 1,356 个共享词条的四语言、插值参数与源代码覆盖检查通过，另核对编译器实际生成的原生键。
- iPhone 四语言聊天、设置、识别选项界面测试通过，保留 16 张截图。
- Watch 四语言待录音及更多菜单界面测试通过，保留 8 张截图。
- 合入最新 main 后，4 项真实模型 VAD 连续性测试通过，覆盖批次、重启、取消、时钟回绕、非连续范围和重采样。
- 最终 iPhone、内嵌 Watch 与小组件的 Release 构建及 29 项包检查通过；三者均包含四语言资源，版本为 1.15.0。

双端界面用例在合入 VAD 修复前完成。合入后重跑包回归、上述 VAD 测试、Release 构建、资源及版本检查。

本轮没有安装到用户设备。语言 token 的回归检查不等于四语言的语音准确率验收；日语、韩语和英语的真实录音识别质量、混合语言准确率和手机耗时仍需分别测量。文案已做常用操作及术语校对，长篇帮助与错误文案仍需母语使用者审阅。
