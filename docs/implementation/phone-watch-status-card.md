# 手机手表状态卡（2026-10-15）

按用户提供的黑色波点参考图，在转录页列表顶部增加手表状态卡；空聊天首页增加紧凑状态入口，点击进入转录页。输入框获得焦点或已有聊天内容时不显示首页状态入口。

卡片保留黑色圆角、状态圆点、手表图标与白色波点。录音中点阵以波浪运动，静音/结束时静止；这是状态动效，不表示真实音量。遵循减少动态效果设置，应用非活跃时停止波浪动画。卡片文案支持大字号自然换行。

沿用实际接收并存储的 Watch 状态，LibraryModel 刷新时读取最新采样时间的摘要，也支持首段音频到达之前的状态。查询不创建录音或回执，仍排除已删除会话。手机不会凭状态声称“已连接”或音频“刚刚同步”，只显示“状态刚刚更新”和手表报告的待同步片段数。

录音动效只在非系统缓存恢复的摘要、采样和接收时间均在 30 秒内，且手表报告最近采样不超过 10 秒时启动。5 秒刷新一次新鲜度；过期、未知或时钟明显超前时显示等待/待更新状态。时间容许最多 5 秒设备时钟差。这是保守的状态提示，不保证持续在线。

## 首次真机连接与错误横幅

真机首次录音发生于身份握手之前，状态中的 receiverLibraryInstanceID 尚为空。ArchiveStore 仍拒绝接收该状态，不能将它当作本机状态或文件确认；手机接收协调器将其视为等待握手，并尝试发送本机身份，不再弹内部 ArchiveStatusError 1。明确属于其他资料库的状态仍被拒绝，显示操作提示。Watch 接收有效身份后跳过状态发布节流，以免停止录音后一直保留未绑定的旧状态。

状态提示使用单独的 statusFailure，验证通过的手表状态会清除此提示，不会清除音频处理等其他错误。全局提示增加可访问的“关闭提示”按钮，移入页面底部 safeAreaInset 以避免遮住顶部导航。新增协调器恢复/首次身份测试与横幅关闭 UI 测试，验证结果见 device-sync-install.md。
