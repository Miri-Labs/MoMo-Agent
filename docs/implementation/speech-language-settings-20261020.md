# 转录识别语言设置

设置 → 高级设置 → 识别语言提供自动识别、普通话、粤语、英语、日语和韩语。默认自动识别，仅在用户手动选择后更改，不读取所在地、系统语言或系统地区来调整。选择保存在手机本地，应用重启后恢复。

固定语言用于减少自动识别的语言误判，不保证每段音频都识别正确。多种语言交替时可选自动识别。

## 生效范围

- 每个识别请求在提交时读取一次语言选择。切换设置不改变已经提交的请求，后续请求使用新语言。
- 手机启动时先恢复设置，再启动转录协调器和模型预热。
- 分片分析、VAD、窗口 ID、检查点和资料库的配置指纹保持原值。切换语言不会触发历史录音重扫或重转录。
- 每份新识别结果另存包含实际语言配置的识别指纹，已有文字保持原样。

## 模型与资源

Core ML 使用已有的语言输入：`auto=0`、`zh=3`、`en=4`、`yue=7`、`ja=11`、`ko=12`。切换时只更新语言配置和识别指纹，复用已加载的模型和预热形状。

Sherpa 在语言改变时释放旧识别器，再以新语言创建识别器；同一语言继续复用。两种后端沿用现有串行识别队列，VAD 不受语言切换影响。
