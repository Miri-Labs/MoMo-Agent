# 转录页首次进入的横向对齐

用户反馈刚进入转录页时内容偏左，手动滑动后才恢复。代码中，日期页宽由相对容器推导，初始位置由日期绑定和 `ScrollViewReader` 共同设置。绑定未指定锚点，主动定位使用左侧锚点；布局校准只观察内容总宽，没有观察标签页实际显示宽度。

本次将每个日期页的宽高明确设为当前分页区域的尺寸，让懒加载列表在有内容、加载中和空状态下使用相同的页框。日期绑定与主动定位统一使用左侧锚点。实际显示宽度或内容总宽变化时重新定位到选中日期，日常滚动偏移不触发校准。外层页面填满可用区域。

按天保存纵向阅读位置、首次定位到最新记录和左右切换日期的逻辑保留。现有首次进入界面用例新增左右边界断言，要求无需滑动就处于正确位置。

这些修改基于代码检查。本轮按用户要求不启动模拟器回归，尚未取得新版本的真机画面。
