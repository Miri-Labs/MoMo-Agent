# 手表录音期间的重复计算与写盘

版本：1.18.5。基线：`ec64ceba6f53564c811ac3209e6628610d32c44c`。

## 已确认的问题与修改

1. `AACSegmentWriter.append` 原来为每个输入块创建 `AVAudioPCMBuffer` 和转换回调容器。现在每轮录音复用一个有界输入缓冲区，转换同步完成后再填入下一块。每次设置实际帧数，短块不会带入上次缓冲区的尾部。重采样、AAC 编码与分片校验照常执行。
2. 音量投递已有可见性门控，但音频回调仍在屏幕不可见时逐采样计算 RMS。现在隐藏波形时省去 RMS；单声道直接复制采样，双声道继续混合。显示波形时立即恢复音量计算。录音数据与连续性检查不依赖波形是否可见。
3. 同步扫描会重复保存相同的控制消息与文件游标，包括空队列的零游标。账本启用 `WAL` 和 `synchronous=FULL`，原来的无条件 UPSERT 会执行重复更新。现在仅在游标变化时更新行，实际进度与归零仍然持久化。

这些修改不改变抬腕同步、后台同步时机、60 秒分片、16 kHz 输出、24 kbps AAC、录音中断恢复或收到手机持久回执后才清理原音的条件。完整解码检查、哈希校验与原音持久化继续保留。
