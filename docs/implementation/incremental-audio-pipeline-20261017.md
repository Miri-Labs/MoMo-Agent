# 增量分析与有界音频复用

基线 `7d4f4a1`。用户授权学习公开实现并优化后推送 main。本轮保留 SenseVoice、原音归档、窗口身份公式、当日优先、显式批次与重试范围。

用户补充要求不止研究录音，已完成[Omi 跨模块设计核对](../plan/omi-design-review-20261017.md)。本轮落实可恢复的增量派生处理，记忆、中文检索与建议反馈闭环保留为有证据的后续建议。

## 取舍与实现边界

- 参考 Sherpa-ONNX 的持续 VAD 和 PCM 交接、WhisperKit 的消费确认与取消唤醒，以及 Omi 的原音先保管、派生失败不删除原音。只学习设计，不引入这些项目的新依赖或代码。
- 自动分析在一个已领取的有界输入快照内延续 VAD 与转换器，逐个发布稳定窗口和确定的覆盖。读取批次与识别窗口分开；分析可在识别期间继续，但最多留一个未消费的分析页。
- 未封闭输入保留 VAD 的不确定尾部；“当前未检测到说话”不能确认刚读取的全部尾部都是静音。窗口上下文按已读取位置计算，checkpoint 只推进确定覆盖；真实封闭边界才覆盖最终尾部。
- 最后一页将“等待更多输入”的身份记在实际未处理尾部，避免原地重放同一快照；身份只来自本次领取的输入，不将分析期间新到达的文件误记为已经检查过。
- 分析过的 16 kHz PCM 以有界缓冲供识别复用。保留窗口、padding、来源身份和文件哈希检查；缓存淘汰后回退既有顺序读取。缓存不构成持久完成状态，也不能替代原音 lease。
- Archive 每页事务登记窗口和覆盖，最后一页才结束尝试、记住输入身份并释放输入。取消、删除、修订和后台到期先停止原生读者，再释放 lease。重启从持久范围恢复，不保存模型内部状态。
- 单个分析快照仍至多领取约 120 秒输入。新流程可跨原先 10/64 秒的函数返回点延续状态，已注册窗口保持原样；新窗口的分析锚点不保证与旧批次切法逐项相同。源帧核心不能重叠，覆盖按并集核算。
- PCM 缓存和读前均有固定容量；禁用预取时按消费需求推进。更高优先级分析可终止当前快照，未提交尾部以后有限重放。同级已登记窗口照常轮转；同级新分析在当前有界快照结束后领取，避免两个未发布页的生产者互相抢占而没有进展。历史与实时共用现有调度和识别实例。

## 验证计划

验证增量首个窗口在最终分析结束前可用、VAD/转换器在同一快照内连续、PCM 命中减少重复转换、缓存失效后的回退、原音被修改时拒绝缓存、背压容量和取消唤醒。覆盖中途提交后取消/重启、删除与修订屏障、当日抢占、暂停和后台到期。运行真实模型回归及 iPhone/Watch/Widget Release 构建和实际包核对。

性能结论按实际读取帧、缓存命中和诊断时间记录；不以代码结构或 Mac 回放代替手机耗电与全天吞吐测量。

## 实现与已有证据

- `SpeechAnalysisStream` 使用一个待消费页的有界交接；关闭读前后按消费者请求推进。stream 取消、消费者释放以及直接取消 SpeechAttempt 都会唤醒原生生产者。生产者结束后才允许释放原音 lease。
- PCM 环形缓冲容量为最大核心帧数 + 16 秒强制 flush 间隔 + lookahead + 少量读前；成品 PCM 最多两个窗口。默认配置这两部分约 4.8 MiB，不包含 ONNX 模型、原生解码器和临时数组；不保留整段录音的 PCM。
- Archive 中途提交保留 attempt 和 lease，只持久化窗口与实际覆盖。新分析可抢占低优先级快照；同级有界快照不会在尚未交付时互相抢占。既有 schema、窗口身份公式与配置指纹保持兼容。
- 本地隔离检查已通过调度/恢复/积压 17 项及 stream 背压 3 项；隔离环境使用 WAV/SHA 适配，仅证明这些算法与并发行为，不代替 Apple 音频验证。
- 首轮完整原生验证：[运行 39031169149](https://github.com/xilanhua12138/MoMoAgent/actions/runs/39031169149)，源码 `c5f9f4c`：Archive 164 项、Agent 19 项、Speech 35 项、协调器 4 项（含参数化暂停/后台到期情形）通过，iPhone/Watch/Widget Release 模拟器构建通过，实际包 27 项检查通过，版本为 1.5.0，内部版本 23。之后新增 AAC 对照、开放尾部与直接取消唤醒验证，最终结果见 [PR #2 的检查](https://github.com/xilanhua12138/MoMoAgent/pull/2/checks)。

该运行的 `incremental-pcm-diagnostics.json` 记录同一个公开中文窗口：缓存识别复用 79,840 模型帧，新增源音频解码帧和转换帧均为 0；消耗缓存后从原音识别需要读取并转换 90,112 帧。两次均重新校验 242,988 字节原音，识别文本、tokens、时间戳与原生 JSON 一致。首次识别还包含模型冷加载，因此这不是端到端耗时 A/B，也不据此声称手机省电比例。

本轮无物理 iPhone/Watch 的安装与全天续航验证；模拟器 Release 构建没有签名，也不是 App Store 交付产物。没有执行大字号测试。
