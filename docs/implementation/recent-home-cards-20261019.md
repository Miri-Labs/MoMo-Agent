# 首页近期帮助卡片

首页卡片承接用户最近正在做的事情，点击后带着来源与具体背景进入聊天。每日总结单独处理：用户确认时间为每天当地时间 **21:00**，回顾当天截至生成时已有的资料；本次卡片修复没有接入每日总结或系统通知。

## 原因与修改

原生成器要求时间窗口已定稿、全部转写完成且至少有 20 个有效字符，超过输入预算的整段内容直接跳过。生成缓存又依赖整个窗口的版本，播放可用性、处理状态或追加正文都可能清空整批卡片。生成失败和短暂读取失败在首页表现为留白。

- 优先选择生成时最近六小时的可读正文，按发生时间由近到远取最多八段。短句和仍在同步、转写的资料均可使用；单段最多取 3 KB，总正文预算最多 12 KB，并服从模型上下文余量。
- 提示词要求提出当前能完成的具体帮助，说明近期背景与预期产物。姓名或时间不确定时省略该细节；不因缺少结束信息排除已知内容。仍允许在没有具体可帮事项时返回空结果。
- 卡片只引用实际发送给模型的段落。追加正文和播放状态变化保留有效建议；修改、删除、模型或个人上下文变更仍核对来源。某张卡片失效不会清除另一张来源仍有效的卡片。点击时再次核对后才发送。
- 点击后的可见请求包含卡片主题、背景和结果要求，相关资料继续走原聊天引用链路。
- 新资料触发刷新，频繁更新合并到至少两分钟一次；缓存三十分钟，失败重试最长等待五分钟。升级清除旧卡片策略留下的十五分钟等待和一天退避。
- 前台安排一次等待任务，在等待时间结束后继续检查，不依赖下一次导航或转写事件。聊天运行时取消自动生成和等待任务，结束后恢复。后台继续复用已有系统任务，不承诺系统固定唤醒时间。
