# 转录时间轴顺序与默认位置

按用户要求，每天的转录时间轴从早到晚展示，首次进入时默认显示最底部的最新内容。手动向上阅读后，刷新继续保留当前阅读位置；每个日期仍各自保存位置。

改动仅在时间轴展示层反转档案返回的倒序列表。档案查询、Agent 近期上下文、播放预热和搜索排序继续沿用原有契约。节点下方的间隔改为当前记录结束到下一条较晚记录开始的时间，与连线方向一致。

滚动使用 SwiftUI 的[默认锚点](https://developer.apple.com/documentation/swiftui/view/defaultscrollanchor(_:for:))：可滚动内容默认锚定底部，短内容靠顶部排列。已有 `scrollPosition` 继续保存和恢复各日期的手动阅读位置；首次选中某日期并读到非空快照时，仅定位一次到最后一条。相邻日期的预加载不算首次打开，刷新不再次指定最新记录，避免覆盖用户上翻后的位置。

原生界面回归使用昨天 08:00 到 19:00 的 12 个真实档案片段，在没有预先加载当天快照时打开界面，检查异步加载后位于底部并显示 19:00。另用 UI 自动化的真实手势上翻到 08:00、下拉刷新并切换聊天/转录标签，检查阅读位置保留；不用程序修改 UIKit 偏移来冒充用户拖动。现有时间轴 UI 用例按新顺序选择最新记录，并向下滑动回看更早内容。

版本为 `1.8.3`。iOS 27 模拟器上的 6 项日期/原生布局集成测试及 5 项时间轴 UI 测试全部通过。验收包括空档案、读取失败重试、跨时区重复时间、异步首屏到底、日期切换、详情回听、短内容、下拉刷新及标签切换后保留位置。
