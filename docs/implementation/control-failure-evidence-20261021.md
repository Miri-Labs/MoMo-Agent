## 修改

`ControlTransferDiagnostic` 保留现有最近 32 条结果，另保存最近 16 条失败。成功回执不会再挤掉失败记录。失败仍包含消息标识、类型、通道、本地期限或 SDK 回调来源、时间、可达状态和错误码，不记录消息正文及错误描述。

旧文件缺少 `failures` 字段时，从已有记录恢复失败；解码同时限制两个数组长度。该修改改善诊断证据，不改写同步确认条件、重试策略或录音删除条件。
