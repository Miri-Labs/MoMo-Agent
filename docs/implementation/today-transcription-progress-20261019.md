# 当天录音整理状态

## 改动

当天录音持续增加，已处理时长除以已收到时长会长期接近 99%。转录页现在单独显示当天的待处理录音时长，例如「待处理 2 分钟录音」，并保留暂停、失败和待同步信息。这里的时长表示录音长度，不是预计等待时间。

当天不显示百分比、进度条和独立的「后台继续整理」按钮。已收到的录音处理完后，沿用原有完成判定收起处理状态；后续新录音到达时更新待处理时长。

历史日期保持原有百分比、进度条和操作。此次不修改录音、同步、转写调度和后台任务协议。

版本为 1.10.5。

1.10.6 移除正常处理时的阶段说明。准备、转写和排队阶段只更新已有进度，不再轮换「正在分批分析原音」「正在按录音顺序逐段生成文字」等文案，也不保留空白提示行。暂停、系统挂起、资源限制、缺少原音和失败提示继续显示。

参考 Workspace `design.md` 的 Clear 原则，减少无意义状态信息；本次沿用现有布局、字体和颜色，仅收起正常阶段说明。
