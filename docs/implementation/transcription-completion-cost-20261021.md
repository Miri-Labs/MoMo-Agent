# 转录完成检查的重复计算

2026-10-21。验收目标为：手机处理已接收的 1 小时音频，分析、识别和结果落盘合计不超过 300 秒。同步传输单独计时。1.18.1 已完成两组前台真机标准样本测试，分别用时 75.03 秒和 115.91 秒。

## 问题与修改

`ArchiveStore.updateCompletedChunks` 在每次分析提交和识别提交后运行。原实现读取整轮录音的片段，并为每个片段重新排序全部分析覆盖记录。已经完成的片段也再次写入 `transcription_jobs`，使时间线版本无意义地递增。

现在先选择尚未完成、未被替代的任务。覆盖区间只合并一次，再扣除待识别窗口的上下文区间。只有整个片段均已完成分析、且不再被待识别上下文占用时，才更新任务。

原音、转录快照、模型权重、VAD 阈值和配置指纹均未因本修复修改。不同模型配置的覆盖不能混用；采样缺口、跨片段上下文和被替代任务仍受原有约束保护。

## 局部测量

从手机取得的资料库副本通过 SQLite `quick_check`。选择其中一轮录音：665 个片段、5,238 条已分析覆盖记录。在独立副本上调用原有完成检查，使用 Mac 的 Swift Debug 构建；没有修改手机资料库。

| 检查 | 原实现 | 修改后 |
| --- | ---: | ---: |
| 首次调用 | 281.69 ms | 38.94 ms |
| 第二次调用 | 245.87 ms | 0.67 ms |
| 第三次调用 | 256.37 ms | 0.49 ms |
| 每次重复写入已完成任务 | 665 条 | 0 条 |

这些数值只反映完成检查的成本，不代表模型加速比或整小时转录速度。

本地证据在 `tmp_agent_output/20261021-asr-throughput/`：`completion-before.log`、`completion-after.log`、`CompletionBenchmark.swift`、`archive-tests.log`。含个人资料的数据库副本不提交到 Git。

## 验证与剩余诊断

- MoMoArchive 的 225 个测试通过。新增测试覆盖采样缺口、跨片段待识别上下文、不同配置覆盖隔离、失败任务恢复、被替代任务，以及重复检查不写库、不刷新时间线。
- 合入最新 main 的离线句间停顿优化后，真实 VAD 的 5 项测试、15 个参数场景通过。手机整小时测速改为核对完整文本的字符错误率和已处理覆盖，不再假定每句话必须对应一个窗口；测试包 `build-for-testing` 和真机执行均通过。
- 1.18.1 的签名 Release 构建通过，产物静态检查 29 项通过；这些检查不等于安装或运行验证。
- 手机 1.18.0 的诊断还记录了冷启动 VAD 重放：一次取消前重放约 50 分钟历史音频，占用约 30 秒；另一次准备操作用时约 52 秒，其中重放约 130 分钟历史。该路径仍需优化，不能靠跳过音频缩短耗时。
- 同一诊断进程后续记录了 13 个已完成识别窗口、约 2.05 秒原生推理累计耗时。这些窗口只有约 15 秒语音，不能据此判断整小时性能。
- 转录历史快照表约 1.5 GB。它保存版本与引用依据，本次没有删除或改写。该表对处理耗时的影响尚未单独测量。
- 最初安装请求返回 CoreDevice 4016、设备状态 unavailable。对已有手机执行一次 `devicectl manage pair --device <已配对设备 ID>` 后，成功读回同步诊断并原位安装 1.18.1。没有取消配对或卸载。该步骤只记录本次恢复结果，后续仍以真实文件读取、安装与启动结果判断连接。

## 整小时真机结果

源码 `44ef7f6c8523105052269a984cd95e140fb561a0`，iPhone 17 Pro，iOS 27.2，SenseVoice Small 原版 INT8 ONNX，sherpa-onnx/Core ML，档案 batch 上限为 2。使用优化编译的 Debug 测试宿主，前台执行；低电量模式关闭。测试前后系统 thermalState 均为 nominal。

| 一小时工作量 | 处理总耗时 | 模型加载 | 原生识别累计 | 已处理音频 | 文本字符错误率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 稀疏语音，首次加载 | 75.03 s | 33.77 s | 12.34 s | 3,600 s | 0 |
| 密集语音，已加载模型 | 115.91 s | 0 s | 89.83 s | 3,600 s | 0 |

两组均完成全部已接收范围并进入 idle，测试零失败。密集组识别了约 2,347.96 秒语音核心，共 540 个窗口；稀疏组为 60 个窗口。原音接收后再开始处理计时，测试导入分别花费 0.85 秒和 1.32 秒，单独记录。

音频由公开中文语音片段重复构成，密集组每次追加 750 毫秒静音。这里验证的是固定工作量的前台吞吐量和该样本的文字完整性；自然对话准确率、FunASR Nano、后台调度等待、历史记录冷启动重放，以及全天耗电仍需分别验证。

结构化结果见 [真机测速数据](asr-throughput-iphone-20261021.json)。本地原始证据在 `tmp_agent_output/20261021-asr-device-retry/phone-throughput.xcresult`、`phone-throughput.log` 与 `attachments/`。

测速结束后原位恢复签名 Release 包，启动成功，设备版本核对为 1.18.1。正式资料库身份未变；安装前诊断中的 4,382 个片段 ID 全部保留，安装后诊断为 4,402 个。此项核对覆盖接收记录，不是逐文件原音校验。安装、启动、版本和条目比较分别记录于 `phone-release-restore.json`、`phone-final-launch.json`、`phone-final-version.json`、`receive-preservation-check.json`。
