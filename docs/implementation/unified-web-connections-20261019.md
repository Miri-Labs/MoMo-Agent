# 联网统一管理与移除行动记录

基线 `930a02f`，分支 `fix/unify-web-connections`。共享配置版本 1.10.2，内部构建号 51；本次不生成或安装 App 产物。

- 设置首页仅保留「连接与权限」入口，移除独立「联网服务」入口及页面。
- 同页提供联网开关，点击「配置」原地展开搜索/读取服务选择与 DeepSeek、Exa、Tavily 配置。各服务的 API Key、根地址、显式连接测试、保存和移除均在原页操作。首次打开页面不会发出外部服务请求，联网默认关闭。
- 复用原有 `WebSettingsModel` 和 `WebAccess`，保留钥匙串、配置版本校验、关闭取消请求及旧密钥清理。保存配置不会自动开启联网，折叠编辑器丢弃未保存的密钥并取消测试；重新打开编辑器读取当前配置版本。
