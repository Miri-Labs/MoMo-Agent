# 多层记忆、检索与整理

本轮从 `74ca8dcac73c466ad03eaf1ef8bb84b592c5431e` 实施。采用已完成研究中 OpenClaw 的每日和主题档案、按需召回与 Dream 分工，以及 Hermes 的会话搜索、主动记录和任务经验。代码继续使用 Swift、Pi、SQLite 和原生后台入口。

参考快照：[OpenClaw](https://github.com/openclaw/openclaw/tree/c1483e015fb618433fc17509f488945c7af81cb5)、[Hermes](https://github.com/NousResearch/hermes-agent/tree/71fa6e176aea53e1e4a4e16bdd0d2c88a566aaa8)、[Hermes Dream 插件](https://github.com/itpartypattaya/hermes-dreaming/tree/8f35aac1acc02faa70d1e970643f21aac718788c)。插件能力与上游核心分别采用，不把社区插件称为 Hermes 核心默认行为。

## 保存与输入

`Persona` 仍保留 SOUL、USER、MEMORY 等常驻文件，同时增加：

```text
memory/YYYY-MM-DD.md
memory/entities/people/<实体>.md
memory/entities/projects/<实体>.md
memory/topics/<主题>.md
memory/imports/legacy/<旧分类>.md
memory/imports/overflow/<分类>.md
skills/<任务类别>/SKILL.md
reviews/dreaming/YYYY-MM-DD.md
DREAMS.md
```

档案没有 4096 或 8192 字节的个人历史总量限制。单次常驻编辑限制为 1 MiB；动态档案按约 1 MiB 分文件，大条目继续分段保存。聊天工具的一次新增限制为 128 KiB。原始聊天、附件正文和录音转录继续由各自原始数据库保存。

每轮常驻正文预览约 8192 字节，相关检索预览约 6000 字节，事件意图另有约 6000 字节预算。这些是字节预算，不是精确 token 数。每个逻辑请求及重试继续冻结快照；遗忘会撤回失效上下文。

Markdown 正文保留自然段落、列表和链接。HTML 注释携带来源、状态、事件时间、版本关系和评分。普通 Markdown 文件也可读取，标为旧资料、尚未核对来源。存储与检索不会把正文中的角色声明或命令提升成系统指令。

## 模型入口

提示词保留上游的主要行为，适配集中在原生工具和产品边界：

| 来源 | 保留的行为 | MoMoAgent 适配 |
| --- | --- | --- |
| OpenClaw AGENTS 模板 | 每日笔记与长期记忆分开，先读取再修改，记下重要决定和背景 | 使用已有 Swift 文件、版本校验及分页工具，不要求模型操作 shell |
| Hermes memory guidance / tool | 主动记录有用事实，保持条目精炼，任务方法另存 skills | 使用 memory、skill_view；一次明确偏好或纠正即可记录 |
| Hermes session_search | 用户提到过去时先查历史，减少反复交代 | 查询本地 Pi 原始聊天，返回角色、来源和续读游标 |
| Dream 整理流程及社区插件 | 空闲时整理来源、关联旧记忆、合并更新，记录整理原因 | Light/REM/Deep 保存检查点；后台只编辑记忆，不执行外部动作 |

录音中未知说话人的“我”不能直接归到用户；没有录音结束事件不阻止处理已到达正文。明确完成或取消承诺时，宿主保留完整旧版本，模型可以自然改写结果。相同事实的常驻层与档案层若在同一批得到一致更新，只发布一次；不同引文可来自同一个已验证来源。没有为某个测试名字、软件或句式增加提示词规则。

| 工具 | 用途 |
| --- | --- |
| memory_search | 中文关键词与本地语义召回，支持日期和目录范围 |
| memory_get | 按文件版本分页读取正文和来源 |
| session_search | 查询原始聊天，区分用户与助手，支持会话和长正文续读 |
| memory | 常驻分类编辑及动态档案新增、纠正、替代、结束、归档和遗忘 |
| memory_feedback | 区分取出、使用、用户反馈和明确确认 |
| memory_status | 查看档案、待处理来源、索引和整理进度 |
| skill_view | 按需读取已经验证的任务经验 |
| memory_intent | 保存用户明确提出的事件条件意图，供后续聊天使用 |

检索结果是预览；编辑需要读取当前文件版本。长正文通过 `nextOffset`、`nextContentOffset` 和 `nextEvidenceOffset` 续读。长引文可能只返回预览，`quoteIsPreview` 会明确标记；原始来源和导出文件保留完整内容。

明确陈述与纠正可以当次写入。归纳稳定习惯仍需要跨日期的独立原话。未知说话人的录音只支持事件记录，不据此认定用户身份、偏好和个人承诺。写入后继续回答当前任务。

## 整理与一致性

聊天完成后触发空闲 review；压缩前保存待整理来源检查点。Light 保存当前原始候选和检查点，REM 保存关联档案的读取版本，Deep 生成带证据的编辑方案。REM 和 Deep 共用有截止时间的模型调用。提交前保存方案，重新验证来源和版本，再用已有 redo journal 发布多文件内容和检查点。

默认一次空闲执行最多处理 8 个小批次，每批最多 24 个新来源，批次之间检查取消、时间和前台状态。自动摘要入口先处理 1 个记忆批次，让其他总结继续推进。一个会话读取失败会单独退避；其他来源仍可整理。整理日志不作为新事实来源，也不进入普通记忆索引。

后台索引按文件修订执行。向量计算在 Persona 文件锁外进行；写入时再次核对版本和遗忘记录。文件列表缓存数量与文件标识，避免打开设置时重复解码全部档案。

替代和纠正保留旧版本，并同时撤回每日投影。遗忘清理相关档案、摘要、索引、向量、候选工作和待审核方案，并保存来源与条目墓碑。恢复旧备份时，现有墓碑优先。原始聊天和录音仍保留，记忆层不再自动学入已遗忘来源。

文件版本包含内容和文件标识，拒绝过期编辑及恢复相同正文后的旧编辑令牌。数据读取采用受控相对路径，拒绝越界路径和归档目录中的符号链接。

修改固定分类时只记录被替代正文的时间屏障，不再把所有旧资料一起排除。旧资料不能恢复已被替代的同文事实，其他项目和日期仍可回补。升级前已经存在的旧版隐私截止时间继续保留，避免取消用户过去的删除效果。

## 手机资源与当前边界

记忆任务使用 utility 优先级；新消息取消后台模型与索引任务。SQLite 连接和语句在同步步骤内关闭，不跨模型请求或等待持有。主动查询的向量计算也在 Persona 文件锁外进行；每轮自动预览只做关键词召回，避免发送消息时加载 NLP 模型。索引或动态档案读取失效会明确降级，保留文件并继续使用常驻上下文回答。

中文关键词覆盖完整索引。语义向量使用系统可用的句子模型；缺少句子模型时尝试词向量平均。向量计算最多读取每条的 8192 字节，语义扫描最多 2048 条候选，超过后返回 partial，用户可用日期或目录缩小范围。语义模型缺失时返回关键词结果并说明降级。结果按相关性、反馈、事件新鲜度和多样性排列，不能把这些分数当作事实真伪证明。

事件意图按录音会话或档案路径限定范围，使用 armed → ready → cooldown 的状态和有限触发次数。确认完成后才开始冷却，次数用尽进入 completed；到期及取消分别结束。旧事件重放不重复触发。它只把条件到达的信息交给后续聊天，不保证后台通知或某一时刻执行。精确时刻仍走系统闹钟和待办工具。iOS 决定后台何时唤醒，进入前台也可继续消化积压。

原始会话工具按数据库主键续读，每页最多扫描 512 条存储记录，工具记录也计入扫描量。空页带有 hasMore 和 nextEntryCursor 时继续读取，不能解释为没有历史。正文分页与会话分页分别返回游标。

设置提供档案浏览、来源、旧版本、纠正、遗忘、导出、合并备份和索引重建。可选写入审核默认关闭；开启后，聊天与 Dream 编辑均暂存，采用时再次核对版本。用户直接在设置中纠正属于明确的人工编辑。

## 验证记录

本轮增加了迁移与大文件分页、中文搜索、索引重建、版本失效、每日投影撤回、遗忘与旧备份、即时偏好、审核、事件意图、压缩检查点及上下文撤回测试。原有 Dream、Pi 实际持久化、录音来源、取消和吞吐测试继续参与回归。

本轮已集成远端 `7a6e25e`，保留同期的同步、回听和连接设置改动。版本为 `1.10.0`，手机、内嵌手表与 Widget 内部构建号统一为 49。

- 合并后的 `MoMoAgentTests`：55 个 XCTest 无失败；Swift Testing 报告 219 个测试通过。常规回归跳过 5 个需要额外环境的用例，其中本轮真实模型与容量测试另行执行。日志：`tmp_agent_output/20261019-memory/agent-tests-final.log`。
- 真实模型使用 DeepSeek `deepseek/deepseek-v4.1-flash-1017`，通过 OpenRouter HTTPS，使用用户指定的现有连接凭证；测试输入均为虚构资料。已通过三轮真实聊天的“保存并回答 → 纠正 → 新会话召回 → 遗忘软件并保留职业 → 再次核对”流程。日志及答案：`live-final.log`、`live-final/conversation-*/answers.json`。
- Dream 固定集覆盖 15 类行为、每类 4 个变体，共 60 个中文场景，各执行 3 次。模型输出经宿主校验与实际提交，保留输入、工具响应、方案和档案。自动检查与 Codex 语义复核分别记录，不把出现旧软件名、否定句或历史值直接当作错误。最终协议运行 180/180 通过自动检查；另外由 Codex 阅读 84 个关键场景的最终档案。结果与逐项来源检查记录在 `quality-audit.json`，原始结果保存在 `live-accepted/`。
- 容量测试实际保存并重新打开 100000 个 Markdown 条目、180 天档案、50000 个已处理与 50000 个待处理检查点，以及 5000 个旧会话检查点；空整理后数量完整，常驻输入保持有界。档案正文与元数据共 76844050 字节，存储测试内部计时 29.62 秒。此项在 Mac 执行，未做 10 万条向量索引或手机耗电测试。报告：`scale/storage-scale.json`。
- 最终源代码的 Release iPhone 模拟器与内嵌 Watch 编译通过，未签名。发布包静态检查通过 27/29 项；两项失败是最新 main 尚未配置 Google OAuth 公共 client ID 及对应 callback，与本轮记忆实现无关。检查器自身 23 个测试通过。记录：`native-release-accepted.log`、`release-bundle-accepted.json`、`bundle-auditor-tests.log`。

以上验证产物均位于 `tmp_agent_output/20261019-memory/`。本轮修复了真实模型暴露的日期精度、同批重复更新、自然改写完成承诺、不同长度引文及旧资料回补问题；录音的来源类型由宿主确定为 observed。Codex 逐项阅读还发现一次改期被误标为整项取消，因此补清 outcome 的业务含义，并增加“已有承诺改期后仍有效”的检查。旧的失败日志保留，不用后续成功覆盖早期结果。语义复核仍发现两例把培训素材来源归纳成用户参加培训，未把它们算作来源准确率验收通过；当前没有扩大提示词去追逐这些具体句式。

## 能力与验收对照

本表按研究方案的能力范围记录实现，区分实现与质量验收。Light/REM/Deep 是同一原生任务的持久阶段；REM/Deep 共用一次模型往返，避免手机对同一批资料反复请求。

| 能力 | 当前实现及证据 | 尚需验收 |
| --- | --- | --- |
| 精炼常驻层、每日和主题多文件 | 原文迁移、10 万条/180 天保存与重开、分页及输入预算测试 | 真机迁移峰值内存与大规模索引 |
| 人物、项目与知识页面 | 按 subject 路由，保留来源、争议及替代关系；固定同名场景真实模型检查 | 更复杂的跨来源同名实体辨别 |
| 原始会话召回 | Pi 只读投影，长附件不遮蔽问题，主键及正文游标 | 大会话的手机耗时 |
| 中文关键词与语义召回 | FTS5 字符索引、系统本地 embedding、模型版本、时间与目录过滤、MMR | 中文固定召回集及手机 P95 |
| 自动相关记忆 | 每轮冻结精炼预览，有限可信召回；真实跨会话纠正、召回与遗忘链路 | 独立 Recall@10 测量；无额外召回模型调用 |
| 主动记录、即时纠正 | 前台按需记录、空闲 review 补齐；真实模型写入并继续回答 | 更多连接模型的调用行为 |
| 压缩前 flush、聊天后 review | 原始资料检查点、空闲入口、抢占及重启续跑 | iOS 实际唤醒与到期记录 |
| Light/REM/Deep 与候选结果 | 持久工作输入、读取版本、待提交方案、逐来源结果、独立失败退避；DeepSeek 固定中文场景 | 真实长期资料的批次质量与成本 |
| 晋升与评分 | 直接陈述和推断分通路；记录六个评分分量及独立来源 | 评分权重校准；不把启发式分数当事实证明 |
| 变更、冲突、身份隔离 | 有效期、旧版本、精确 patch；固定场景检查未知说话人、迟到资料与同名区分 | 更复杂的第三方、跨来源及隐含冲突评估 |
| 召回反馈 | retrieved/used/helpful/unhelpful/confirmed 分开；同轮取出回执 | 真实用户反馈后的排序质量 |
| 遗忘与防止再次学入 | 档案、每日派生、索引、向量、工作、备份墓碑及旧请求撤回回归 | 真机中途退出及磁盘故障注入 |
| Dream 日志 | 独立日志、实际结果、原因与来源，禁止循环晋升 | 人工检查日志可读性 |
| 任务经验 | procedure 写入 SKILL、skill_view 按需加载；真实模型保存明确验证过的方法 | 未验证和失败方法的更广模型评估 |
| 未来意图 | 类型、范围、次数、冷却、去重和到期；不扩大工具权限 | 前后台事件的手机验收 |
| 管理、审核和诊断 | 原生浏览、来源、旧版本、纠正、遗忘、导入导出及重建；审核使用读取版本 | 原生界面实机操作 |
| 外部后端 | 保留本地存储和版本化备份协议 | 本期未接入第三方托管后端，符合方案取舍 |

结构与主要行为已经实现。独立中文 Recall@10、来源归属总体准确率、其他代表模型及手机 P95、内存、耗电和后台唤醒仍需验收；固定场景通过不能替代这些指标。当前结果不标记为“全量质量验收完成”。
