# 设备对账与状态报告

对账负责找出两端文件状态的差异，并恢复可重传的原音。状态报告只用于展示手表和手机上次报告的进度。二者通过不同的 WatchConnectivity 通道发送，状态报告不能确认收件、清理手表原音或授权删除。

## 文件对账

`MoMoContracts` 定义 `ReconcileRequest`、`ReconcileResponse` 和文件身份。每项包含录音 ID、分片 ID、音频哈希、清单哈希和完整原音类型。请求另绑定 Watch 设备、接收设备和资料库实例；响应包含请求 ID 与规范编码的请求哈希。Watch 只应用成员与身份全部匹配的响应。

当前每页最多 16 个分片，低于方案的 32 项上限。请求与响应各自最多 15 KiB，控制消息外层最多 16 KiB，给完整收件回执留出编码空间。控制消息仍受 Link 的有界运输队列限制。

Watch 在 SQLite 中保存一轮对账的序号上界、当前游标和未完成请求。每次只有一页等待响应；进程重启后重放同一请求，而不是重新生成身份。已确认并清理的分片仍保留账本记录，允许重新发送 `ReceiptApplied`。新录音不会使本轮查询的成员无限增加。

iPhone 保存请求与响应。再次收到相同请求时，重新检查原音和清单：状态未变时复用响应 ID；文件已经丢失时生成新的缺失响应，不能重放旧的成功确认。响应进入系统运输队列后停止本轮重复提交；运输失败按响应 ID 重新置为待发送。迟到的旧响应回调不能修改新响应。

| 手机响应 | Watch 的动作 |
| --- | --- |
| received，带完整回执 | 按现有回执协议持久保存确认，生成可重放的 ReceiptApplied，再执行符合条件的原音清理 |
| unknown / missing | 原音仍有效时保留并重传；原音已清理时报告无法补回 |
| conflict | 停止自动发送该片，保留现有原音，报告冲突 |
| expired | 停止自动发送该片，保留现有原音；过期状态不能授权清理 |
| deleted | 交给既有删除协议核对录音、来源和删除代次，再执行删除 |

完整原音重传可以修复手机目录内缺失的音频或清单。修复先核对身份、文件大小、哈希和音频格式，并保留收件副本直到事务完成。已有但内容不同的文件不会被覆盖；符号链接路径不会被当作原音。用户从 Files 删除整个录音目录后，仍需执行现有的预览确认恢复流程。已过期或已删除的资料不会被重传重新创建。

文件发送按账本序号分页，避免前几个尚未收到业务确认的文件一直挡住后续文件。系统仍在传输旧副本时，新的缺片重传意图保持待处理；旧传输结束后才准入一次新传输。运输完成与业务确认保持独立。

手机报告缺失、冲突或过期后，Watch 持久保留回执屏障。迟到的旧普通回执不能解除屏障或触发原音清理。缺片重传完成后启动新一轮有界对账；新请求获得重新核验的 received 响应后，才能重新保存有效确认并恢复清理。屏障与运输待办分别保存，提交重传不会提前解除屏障。

## 状态报告

`StatusSnapshot` 使用 `updateApplicationContext`，包含来源设备、来源库实例、持久递增版本、采样时间与角色。Watch 报告当前录音、采样帧、采样率、已采集与已封口时长、待传数量和字节数。手机报告录音数量、待分析数量和待确认数量。

Link 按设备和库实例去重。更低版本不覆盖更高版本；相同版本但内容不同会报告错误。两个库实例的时间和版本不互相比较。手机仍由 Archive 核对 Watch 来源与接收库身份，传输层去重不能代替业务层检查。

从系统缓存恢复的快照保留原采样时间。重复回调不能把旧快照变成新的观察。手机详情显示“手表上次报告已采集”和对应报告时间，分别计算手机已收到、已分析与已转写的范围。报告之后手表可能继续录音，因此不根据一条缓存报告宣布全部同步。

手机状态先于设备身份到达时，Watch 暂存该状态，绑定或经用户确认切换资料库后再核对。接收到状态本身不会触发对账或发送新的状态，避免两端互相触发同步。

## 验证边界

本轮用真实 SQLite、文件、原音校验及生产协调器验证协议、重启恢复、缺片修复和状态接线。测试通过情况及证据编号以[实施记录](status.md)为准。受控运输事件不代表 WatchConnectivity 已在配对设备上通过；系统后台投递、熄屏录音、手机锁屏和 18 小时连续采集仍需真机验收。

代码按既定边界组织：Contracts 保存协议；Recording 保存 Watch 账本与重传意图；Link 管理系统运输准入；Archive 保存手机文件、回执和对账响应；两个 App runtime 串联各自模块。新增协议要求两端使用配套构建，旧端不能解码新消息。
