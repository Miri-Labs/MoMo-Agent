# 首次引导支持手动分页

此方案在用户体验 1.19.1 后由[自动播放短片](onboarding-film-20261021.md)取代，以下保留当时的实现记录。

用户反馈底部三个点看起来可以左右切换，实际却只能等待自动播放。三个场景现在放入原生分页 `TabView`，支持跟随手指左右滑动。圆点改为可点击按钮，每个按钮提供 44 × 44 的点击区域、页码和选中状态。

滑动或点击切换时，从目标场景开头播放。切换使旧页面的计时任务和动画完成回调失效，防止旧页面继续推进新场景。屏幕外场景的 Avatar 停止动画。自动播放、跳过、再看一次及 VoiceOver 的逐步继续操作保留。

版本为 `1.19.1`。本轮沿用用户要求，不运行模拟器回归；构建与设备安装结果另行记录。
