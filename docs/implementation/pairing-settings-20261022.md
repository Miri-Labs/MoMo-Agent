# 配对设置收敛 · 1.23.1

范围限定为网络配置和配对入口。模型、转录、存储、Agent 任务及网络协议不变。

两端入口和页面标题统一为「配对」。日常操作先于配置参数，使用原生 Form、分组、导航和 DisclosureGroup；不添加装饰或自定义动画。

- 手机首页只显示「已配对／尚未配对」和「重新配对／扫码配对」。已保存配置不被描述为实时在线。
- 「网络详情」显示地址和实际传输方式；「手动配置」单独呈现连接信息与设备密钥，保留原有保存、身份检查和钥匙串流程。
- Mac 保留一个远程访问开关、实际连接状态和已配对设备；需要配对时再展开二维码。重新生成二维码、移除设备、网络重试与暂停仍可操作。
- 「网络设置」默认收起。自动设置与自定义地址分开；服务商示例、本机服务地址、SSE 要求等进入「设置帮助」。移除固定入口推荐、教程长段落及重复说明。
- 更新共享网络组件及旧路径文字，确保配对流程里没有失效的「Mac 连接／设备与连接」入口名称。

设计取舍：保留单页堆叠所有参数会继续分散注意力；全部藏进一个高级页又会掩盖配对状态。因此采用「配对状态与操作 → 网络详情／手动配置」结构。配置继续由原模型持有，只有页面展开与输入草稿是本地状态。

验证记录在本轮输出中：Mac Debug、iPhone Simulator 与 Release 构建；手机已配对和未配对的导航及返回；Mac 独立合成运行目录中的分组和高级设置展开。SwiftUI 静态扫描没有高风险发现；现存中等级提示属于二维码尺寸、窗口尺寸和原聊天组件，本次不扩展修改。只验证系统默认字号。

本轮没有自定义渲染或动效，无新增性能采样需求。未做真机、VoiceOver 朗读和完整辅助显示矩阵，设计评分不作为完成证明。
