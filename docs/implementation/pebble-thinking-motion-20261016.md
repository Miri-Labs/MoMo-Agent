# 鹅卵石思考动画

本轮从 `origin/main` 的 `faf7ada` 创建任务分支，接入用户确认的原品牌三块鹅卵石方案：绕 X / Y 轴翻面、前后换位并组合回图标，5.8 秒连续循环，没有分段停顿。

聊天中的等待、思考和工具执行共用一个 Canvas、一个时钟和一份本地图集。切换状态或接收增量快照时继续原动作；正文出现或回复结束后停止。文字 shimmer 保留，顶部 MoMo 角色不变。

手机采用 30 fps、2 倍分辨率，显示尺寸为 32×28 点。174 帧无损图集为 153,360 字节；1024×616×4 的解码像素估算为 2.4 MiB，比 60 fps / 3 倍分辨率方案少约 78%。高刷新率屏幕不重复绘制相同帧，动画帧不修改 DOM。App 无需 Three、实时 3D 计算或外部资源请求。

首次显示使用 1,256 字节的组合静帧，不等待图集解码；减少动态效果开启时不加载图集。后台、离屏和原生视图拆除时取消绘制；视图拆除还会停止文字 shimmer 和等待计时器。恢复可见时接着播放。

几何、灯光、轨迹源码及重建方法保存在 `Tools/ChatRenderer/`。普通资源校验同时验证源码、图集和静帧的 SHA-256。

验证证据位于本 worktree 的 `tmp_agent_output/20261016-pebble-thinking/`。只使用本任务专用 iPhone 17 Pro / iOS 27 模拟器和系统默认字号。WebKit 本地文件禁止脚本回读 Canvas，像素检查使用原生区域截图，不放宽页面安全策略。
