# 移除短停顿优先切段

1.19.13 移除 1.19.12 的“在第 15～20 秒寻找能量低谷并优先切开”规则，以及对应的 `SpeechPauseProfile`、逐帧能量统计和排序。该规则的公开样本结果仍保留在[历史对照记录](pause-aligned-segmentation-20261023.md)，不能由单一句子构造的对照推定通用最优切法。

当前切段按已有 VAD 结果和识别长度约束执行：

- Silero 连续检测语音范围。短语音在检出的边界结束，不要求达到 15 秒。
- 选出的范围超过 20 秒时拆分，剩余尾段按实际长度保留。
- 语句两端保留现有 300 毫秒；内部拆分最多向两侧各取 1 秒原音上下文，再按时间戳和正文归属规则拼接。
- 原生 VAD 的缓冲区刷新、物理文件边界和调度边界沿用现有连续状态处理。没有检出的空白不会因这次修改送入 ASR。

20 秒是当前用于约束识别输入长度的上限。此次恢复已有切法，不改变 VAD 阈值、模型、权重、识别后端或输入框语音流程。

分析标识更新为 `silero6-bounded-speech-v5`，按 v4、v3、v2、v1、旧模型的顺序保留已完成历史。采用新标识而不复用 v3，确保 v4 期间新增的完成结果也能迁移。已完成正文不重新识别；未完成范围继续使用当前规则。

验证包括 VAD 短语音边界、长范围完整覆盖、上下文上限、跨文件长语音拼接、跨两分钟任务、取消恢复、重采样连续性和历史保留。此次不读取或重跑手机历史录音。
