# Avatar 连续转头与录音方案澄清

基线 `6682dc4`，交付版本 `1.1.1`。用户报告 Avatar 看起来不转头且轻微抖动，同时要求重新梳理全天录音方案。

Avatar 的初始姿态已经在挂载时绘制，播放却再次过渡到同一姿态，并停留 800ms，共约 2.2 秒没有实际转头。随后只在约 −5° 到 4.5° 间转动，叠加独立的身体漂移。24 帧延迟计时器之后又等一次显示刷新，增加了不均匀帧间隔。

现在播放立即朝下一姿态前进。左右转角改为 ±24°，每程 2.6 秒，无停留，并关闭独立身体漂移。渲染仍使用既有三维投影和矢量轮廓；只用一个随显示刷新的 RAF 时钟，几何绘制上限 30 帧/秒。隐藏、离开页面、减少动态效果和销毁继续停止动画，重复活跃状态不重启时钟。点击招呼继续使用已有透明矢量层，视图不缩放或模糊。

修改集中在本地定义及构建脚本，未改动固定版本的上游源码。生成产物已重建并通过源哈希核对。没有引入依赖，也没有增加 Watch 绘制工作。
