# 转录跨日滚动位置

用户报告滑到今天后，列表先向下移动，又回到上面。原实现同时使用默认底部锚点、顶部 ID 锚点及选中日期后的再次定位。默认锚点还作用于内容尺寸变化，今天的数据刷新与横向分页会触发不同方向的位置调整。

初始位置和 ID 恢复统一使用底部锚点：首次有数据时定位最新一条，每天只初始化一次，后续保留该日期的阅读位置。默认底部仅用于初始位置，刷新不再按内容高度重新贴底；空列表与未选中的懒加载页面不能覆盖已保存位置。数据归组替换 ID 时继续使用 TimelineModel 的映射。短列表仍顶端对齐，顺序仍从早到晚。

UI 回归覆盖首次进入位于底部、上滑读旧记录、下拉刷新、切换标签、昨天与今天往返，以及手动阅读位置跨日恢复。测试只使用隔离的合成录音，默认字号。

API 行为依据：[Apple defaultScrollAnchor(_:for:)](https://developer.apple.com/documentation/swiftui/view/defaultscrollanchor(_:for:))。

最终实现通过 Release 编译。先前两版实现未通过列表初始位置测试，已改为保留每天一次的首次定位，并统一锚点。最终滚动 UI 回归尚未得到完整结果；用户明确要求停止模拟器并直接安装，不将该验收项记为通过。
