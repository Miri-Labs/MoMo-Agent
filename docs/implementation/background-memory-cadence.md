# 每日 Dream

MoMo Agent 在距上次完成每日整理至少 24 小时、聊天已空闲 10 分钟、模型额度可用时检查新资料。当天首次准入会冻结待处理的聊天和录音页。已授权的日历、待办、到访记录有实质增删改时也可以触发整理。重复同步、仅覆盖窗口变化或常规健康数据不会单独触发。手机资料由模型按需读取，每类独立翻页，游标过期后需重新读取。

## 分批与恢复

- 每次模型会话最多处理 4 页冻结证据，每页约 32 KB。中间批次只更新当前资料涉及的记忆、笔记和说话人标签。末批负责全局整理和晨报。聊天和录音在冻结后新增的内容由下一次每日整理接收。
- 第一页随会话传入。模型核对完一页后，在调用 `read_daily_evidence` 取下一页时可传 `completed_page` 保存进度。缺少确认的读取在失败后重新投递。每批首次准入时，若资料版本已变化，调度器在同一个事务中剔除快照里已删除或已修订的未读录音页，保留新版录音任务和已确认页。模型按返回的 `next_page` 跨页码跳读。全部剩余录音都过期时仍执行一次全局整理和晨报。会话进行中才变化的录音仍在读取和确认时核对版本。
- 会话提交有效回执后，MoMo 在一个 SQLite 事务中确认本批实际交付的页、推进聊天和录音进度，并为快照中的未读页创建下一批。回执分别记录已交付页数 `pages_reviewed` 和本地跳过页数 `pages_skipped`。后续批次继续遵守空闲与额度条件；整份快照完成后开始下一个每日窗口。
- 流式请求等可恢复故障最多自动重试两次，分别退避 5 和 15 分钟。中断后复用冻结资料与已确认页的位置，告诉模型先前实际改动过的目标。Markdown 已落盘的修改对用户立即可见，重试通过读取当前内容和幂等写入来接续。回执会合计此前成功的修改。升级前已排队的重试也能按原页序接续。
- 执行器保留工具进展和空闲超时检查。连续重复相同读取或错误时停止。每日批次必须提交可验证的最终回执；允许在原会话内纠正一次。重复写入、同路径移动、已生效的说话人标记均不计为更新。未解决的工具错误或无效回执保留资料待检查。

## 资料与笔记

聊天分页、历史搜索和晨报取材共用一套筛选条件。未生效的补充消息及 MoMo 自己推送的简报不会进入整理。手机资料按来源翻页，健康数据需明确指定来源。

活页笔记 ID 由库内路径确定，内容版本随正文变化。客户端删除须带上浏览时的内容版本；旧版正文 ID 和过期版本要求刷新。用户删除会记录具体路径，同正文的其他笔记保持独立。
