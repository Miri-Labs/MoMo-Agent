# 后台记忆整理

录音同步先把原文持久化。录音有新版本时，尚未开始的旧任务由新版本接替。模型整理已完成的段落按内容与说话人哈希去重。每批保留独立回执，未处理的段落继续排队。

自动录音整理、聊天整理、深度 Dream 和自动重试共用一个调度窗口。两次自动启动至少相隔 2 小时，聊天空闲至少 10 分钟才可开始。调度器从 SQLite 中读取上一次实际开始时间，重启沿用原窗口。录音和其他整理都积压时轮流获得窗口。运行中的任务先对账，手动 Dream 在当前任务结束后优先执行。同一服务已有额度耗尽通知时暂停新的自动整理。

自动深度 Dream 至少相隔 24 小时，并检查聊天进度、来源版本和笔记内容有无变化。Dream 写出的笔记和投递到聊天的简报不重复触发新一轮整理。手动请求仍可重审已有资料。

SuperAgent 的后台整理允许连续翻页和写后复核。近期连续两轮全部返回以前见过的相同读取结果或工具错误时，执行器将这批标为待检查。无法证实的完成回执也进入待检查，保留未处理进度。服务端按最近一次工具轮次判断是否卡住。Antigravity 的交互式工作线程也使用相同的重复读取检查。

回归覆盖逐分钟重启下的共用间隔、自己的简报与笔记、手动启动、额度暂停、相同录音页循环、连续 20 个不同页码和写后复核。使用本地数据库和模拟模型运行。
