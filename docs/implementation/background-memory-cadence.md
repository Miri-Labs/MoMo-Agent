# 每日 Dream

聊天、录音转录和深度记忆整理共用一次自动 Dream。距上次整理至少 24 小时、聊天空闲至少 10 分钟、有待处理的资料或笔记变化时，调度器启动一次模型会话。自动重试也等待每日窗口。SQLite 保存准入时间，重启不会额外启动。模型服务已有额度耗尽通知时暂停自动准入。手动 Dream 在已准入的工作结束后优先运行。

录音同步照常进行，按来源版本、内容和说话人哈希识别新增段落。每天启动时冻结待处理的聊天和录音，将第一页随任务发给模型。模型通过 `read_daily_evidence` 在同一次会话中继续翻页、核对来源并写入笔记。变更或删除的录音页会跳过。验证最终回执后，在同一事务中确认实际交付的页、推进聊天游标并释放快照。未读资料和运行期间的新消息、录音留给下一次 Dream。自己的笔记更新和投递到聊天的简报不会单独触发下一轮。

SuperAgent 后台执行器与 Hermes 的 Dream 会话允许持续调用工具。SuperAgent 根据工具名称、参数和返回内容检查进展。连续两轮全部重复此前的读取结果或错误时停止；换页、来源内容变化、成功写入后的复核均可继续。无法证实的回执标记为待检查。Antigravity 的交互工作线程也在发出下一次模型调用前检查重复读取。

回归覆盖共用的每日准入、重启、跨来源翻页、只确认已读页、运行期间的新资料、手动启动、额度暂停、相同录音页循环、连续 20 个不同页码和写后复核。
