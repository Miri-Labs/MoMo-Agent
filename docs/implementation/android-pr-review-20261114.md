## 本轮修复

### 聊天页头与角色

- 角标改为采集设备状态：默认显示手表和黄色「手表状态未知」，不再把 Mac `ConnectionState.Ready` 当作手表在线。弹层以手表状态为主，Mac 连接只作次要信息，并保留「查看转录」「连接设置」入口。空会话、有消息页头与未配对的 `EmptyChat` 都使用同一角标。
- 有消息的页头按 iPhone 参数收紧：头像行 72 dp、头像顶对齐、字标 14、字标前 6 dp、底部 8 dp；左右工具各自放在 72 dp 区域。页头用 `onSizeChanged` 实测高度，传给 `ChatScreen` 的 `appearance.headerInset`；渐变高度跟随实测值，不再写死 108/128 dp。
- 静态占位按 `MoMoStill` 原始 300 画布的可见轮廓（约 193/300 高、183/300 宽）缩放，切换前后可见宽度约 51.2 对 51.4 dp；动态 SVG 改为 450 viewBox + 1.5 倍透明 WebView，招呼动作不再裁掉耳朵。
- WebView 仅在 `window.agentAvatar` 与 `svg.life-avatar path[d]` 都存在时标记为已绘制；迟到回调按 token 和 WebView 实例过滤。渲染进程退出时恢复静态占位并重建 WebView。
- 角色跟随前台生命周期；弹窗盖住聊天、切页或退到后台时 `active=false`。读取系统省电状态并传给运行时（低电时 15 fps），减少动态效果沿用系统动画缩放。
- 头像热点保留 48/84/120/144 dp 原尺寸，TalkBack 读出「和 MoMo 打个招呼」。忙碌转空闲后短暂使用 `settled` 完成反馈，首次加载历史会话保持日常姿态。

### 聊天内链接

- 新增 `AgentLink` 解析：严格校验 `momoagent://source/{session}/{span}?version=&generation=` 与 `momoagent://memory/...`，普通 http(s) 继续交给系统。
- 录音引用按 session 找到 `library/session` 来源，读取全部分页，并要求返回的 span 引用与链接的 session、span、version、generation 全部一致。来源删除返回「已被删除」，版本不符返回「引用已过期」，其余失败给出通用提示；成功后可在应用内查看节选并跳到转录详情。
- 记忆引用按完整路径、后缀路径、briefing/user/memory 类型回退解析；刷新后仍找不到时明确提示笔记不存在。聊天内直接打开记忆卡片，不再把 `momoagent` 链接交给系统 `ACTION_VIEW`。
- 普通网页链接打开失败时也给出提示，不再由 `runCatching` 静默吞掉。

### 任务、导航、记忆与手动连接

- 任务列表把协议字段映射为「等待交还电脑」「等待确认」「排队中」「正在整理结果」「待核对结果」「正在执行」「已完成」等可读状态；标题缺失或等于内部 ticket ID 时显示「后台任务」。行可进入详情，详情包含摘要、状态与开始时间，返回后仍停在列表。
- 底部导航改为按内容宽度收拢，选中项使用 8% 墨色浅底，保留 48 dp 触控高度、安全区与读屏名称。
- 记忆列表与详情显示 `projects / atlas / brief.md` 面包屑；搜索同时匹配目录、文件名、类型与正文。
- 手动配置增加 `manualConnecting` 状态：校验期间显示进度并禁止重复提交；成功后清空密钥并自动关闭对话框，设置页显示新连接；失败保留输入并允许重试。

### 欢迎页

- 页头增加「未来演示」标识，场景内说明「尚未读取你的资料」。
- 上下文、请求、回复、结果按阶段逐步出现；默认自动播放，TalkBack 触摸探索开启时改为按钮手动推进，退到后台暂停计时。
- 「跳过」只进入就绪页，必须由「开始配对」进入配对流程。

### 桌面

- 帧流断开时立即清空画面、停止心跳并保留错误；状态轮询不再清除该错误。
- 输入队列在每次发送前复核 `streaming`、画面与控制权；断流后已排队但未发送的点击会被清空，重连前 Mac 收不到输入。
- 前后台切换沿用 `ON_STOP` 暂停、重置按键并交还控制，回前台从只读预览开始。
