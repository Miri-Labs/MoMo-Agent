# 同步调度、续传与回执收敛

本轮接续 1.10.1 的原音小块补传，目标是让断连、后台短时唤醒和历史积压后仍能继续同步。交付验收以完整原音接收及正式回执应用为准。

## 故障证据

1.10.1 真机日志仍出现 `WCErrorDomain/7007`，随后在 15:54 出现 `reconcileResponse` 的 `7012`。Apple SDK 分别将两者定义为对端不可达和等待回复超时。此前的 `7001` 另有 identityservices/200 底层错误，现有证据不能把三者归结为同一个系统原因。

手表曾有四个系统文件任务长期保持 0/100。手机部分接收目录只确认了一次空探测到达，尚没有原音 payload。系统队列存在、状态可达和空探测到达，都不能证明完整同步成功。

独立代码审查确认：同一后台唤醒的第一次空扫描会阻止晚到回执继续处理；定时恢复反复从历史控制消息第一页开始；小块临时中断后切换文件可能导致手机淘汰已有断点。这些应用层缺陷具有可构造的回归场景。

## 状态与所有权

| 对象 | 持久所有者 | 完成条件 |
| --- | --- | --- |
| 采样及原音分片 | Watch `RecordingStore` | 分片封口后即可同步，持续录音无需等待整轮结束 |
| 原音待同步 | Watch `RecordingStore` | 当前接收设备与资料库的正式 Receipt 通过 manifest 和音频哈希校验 |
| 系统文件发送尝试 | `WatchConnectivityTransport` | SDK 任务退出只结束本次尝试，原音继续等待正式 Receipt |
| 小块及完整接收 | iPhone `ArchiveStore` | 持久偏移支持续传；整文件校验和数据库事务完成后生成 Receipt |
| 控制消息 | 现有持久 outbox 与 `ControlInbox` | 对端确认保存 Inbox 后记录交付证明；业务应用按消息类型独立推进 |
| 录音状态展示 | 当前设备范围的状态快照 | 使用版本及新鲜度判断，不授权删除原音 |

## 本轮实现

- 后台唤醒按实际处理的控制消息扣减预算，最多四条。空扫描不消耗预算，后到回执可以使用剩余额度。出站批量调度每次唤醒最多一次，确认后的原音清理最多一个。
- 剩余本地 Inbox 和控制 outbox 纳入恢复条件。后台没有启动麦克风，也不扫描或校验全部历史原音。
- 后台额度在处理回执的 actor 调用中到期时，保留下一次恢复请求。已经写入 outbox 的确认消息不会因本次执行提前返回而失去后续调度。
- 控制扫描位置保存在现有 Watch 账本。ReceiptApplied 和删除确认先于历史采样事件；已获得对端持久 Inbox 回复的消息不再当作未交付历史重复发送。重复正式 Receipt 仍可重新排入其应用确认。
- 即时控制发送有 25 秒应用截止时间。晚到的持久收件回复仍可证明同一消息已交付；接收资料库变更后，旧回调不能把交付证明写入新资料库状态。
- `status_request` 直接在请求回复中返回手机状态与小块能力，减少一次反向即时发送。后台 application context 继续发布状态。
- 小块传输在临时断连或执行预算耗尽后保留当前片段，下次从手机持久偏移续传。手机按最近更新时间淘汰部分副本；只有完整 Archive commit 才生成正式 Receipt。
- 系统文件尝试连续 15 分钟没有真实进展时，先验证手表仍保有匹配的原音，再取消该 SDK 副本。取消后等待 SDK 实际退出才释放名额，同片段冷却 5 分钟；文件扫描位置跨进程保存，让后续片段得到机会。短后台唤醒最多检查一个候选、校验 1 MiB 原音，较大的候选留给前台。
- 发送尝试标识和接收资料库代际持久保存。旧尝试的晚到失败不修改新尝试；传输记录损坏时保留诊断副本，重建新代际并重新观察系统队列。此恢复不修改原音账本。
- 每次使用完整 SDK 文件队列快照对齐发送编号。若本地编号已不在系统队列，接管系统仍持有的真实尝试并重新计算租期；多个副本并存时保留稳定选择，避免任务永久占槽或反复重置租期。
- 新删除消息绑定接收设备和资料库。旧无作用域消息必须由当前资料库重新授权；旧资料库的迟到删除不能直接清理当前绑定下的手表原音。
- 手机从 Archive actor 导出已提交片段的按日接收清单、待确认回执数量和最近真实提交。空探测与部分文件不计入已提交数量。诊断文件最多每 30 秒更新一次，写入失败不阻止接收与回执处理。

## 升级与验证

Watch 账本增加控制交付证明与扫描位置。升级保留原有原音、回执及录音状态；旧版程序不应直接打开升级后的账本作为回滚方式。

最终针对性共享回归通过 151 项：录音 69、传输 59、Archive 诊断与真实小块接收 13、对账协议 10。完整录音套件包含旧 schema 升级；明确覆盖 v5 升级后的原音、录音意图与稳定回执。发送尝试测试覆盖重启后 SDK 与本地编号不同、双副本、取消后等待 SDK 退出、正式 Receipt 与取消交错、晚到回调及损坏记录重建。

Watch 原生回归通过六项：空扫描后的晚到回执、超过预算的本地消息恢复、冷 grant 结束后的新 Inbox、写回执时 grant 到期、旧及外来删除隔离、后台有界处理且不启动采样。iPhone 原生回归通过六项，涵盖即时与后台选路、晚到失败、当前资料库确认及状态请求直接回复。两组使用实际运行时和本地存储，不代表配对设备已经同步成功。

1.10.3 的最终 Release 构建通过，手机和手表的代码签名校验通过，安装包静态检查 29 项通过。Release 检查器自身的 23 项回归也通过。生产代码对应 `65e03b5`，最终原生测试调整对应 `2640545`；新增后台到期测试在调整后单独重跑通过。
