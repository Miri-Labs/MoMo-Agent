# 居中的模型接入按钮（1.24.1）

Mac 的模型接入页使用竖排、同宽的三个大胶囊按钮，按钮组和按钮内的图标、文字均居中。顺序为 Codex 订阅、Claude 订阅、API；Codex 使用 OpenAI 标记，Claude 使用 Anthropic 标记，API 使用系统密钥符号。矢量素材来源见 [服务图标](../design/model-provider-icons.md)。

点击订阅按钮时先检查原有登录，再调用现有 Hermes 认证流程；登录成功后切换到模型选择页。API 按钮切换到独立的配置页，配置页不再显示入口按钮组，返回后重新显示三个入口。三个页面通过显式视图状态互斥呈现，不使用 DisclosureGroup 或行内展开。

返回保留原生 Button 的键盘和辅助功能语义，外观为无背景、无边框的文字。模型页按窗口实际可用空间居中，内容超出较小窗口时仍可以滚动。设置页复用相同的入口与配置页面。验证和登录进程仍由 DesktopModel 持有。

供应商认证、模型验证、网络协议及手机数据逻辑沿用原实现。交付完成后删除本轮临时编译目录，保留安装的应用、私有运行环境及最新安装包与验证记录。

验证：Mac Beta 1.24.1 已在本机安装并启动，代码签名通过。通过实际窗口截图确认胶囊外形、两个品牌标记和居中排版；点击 API 后入口组消失并进入配置页，文字返回恢复三个入口；在较小窗口下三个入口与返回都完整可见。未代替用户完成订阅授权。

补充：状态栏使用既有程序化 MoMo 导出的静态模板矢量，替换 brain 系统符号；镂空双眼随系统浅深色保持可辨。素材源为 `Web/vendor/momoagent-avatar.js`，沿用 `Vendor/BibleStrongAvatar` 的来源和许可证。

引导沿用 main 的 f84c8181：三个场景各 3 秒，总计 9 秒，匹配更短文案及过渡时长；VoiceOver 仍按用户节奏推进。两端共用此实现。手机配对页删除起步说明、同步说明和图片识码入口，移除对应 PhotosUI/CoreImage 状态与解码逻辑，只保留扫码和稍后配对。已移除入口不再作为相机异常时的建议。

交付验证：Mac/iOS Beta 均构建通过，手机发布包审计 29 项通过。首次体验 UI 测试通过，自动引导使用 10 秒等待上限，覆盖首次配对、离开重启继续、稍后配对和从聊天重新进入。测试截图确认配对说明与图片入口已删除；无 GUI 模拟器截图未捕获 WebView 角色，不作为真机 Avatar 视觉验证。
