# 人物声纹、分组与纠错

本次补全匿名说话人、任意人物命名、人物列表，以及纠错影响后续识别的闭环。版本保持 0.0.1。

## 交互

时间右侧的说话人胶囊打开原生选择面板：我、已有人物、添加人物。可靠匹配直接显示姓名；`confirmed` 仍只表示用户明确确认，不因文案变化成为训练依据。人物较多时出现搜索。给匿名组命名默认应用于本录音的同一声学分组；纠正已有姓名默认仅当前阅读段，均可切换范围；当前阅读段涵盖的原始句子一起提交，仍验证每个来源版本。

设置 → 人物与声纹显示实际参与匹配的正样本、排除样本数，支持改名和删除。删除人物及声纹会撤销其姓名标记，保留音频与转录。

## 识别和学习

- 个人声纹不压成单一平均向量。每人、每模型版本、每种正负证据保留最早 8 个及近期 56 个合格样本参与匹配，先过滤质量再截取。原始观察继续保存在档案中，样本数表示当前有效匹配库。
- 与正样本的最高余弦相似度 ≥ 0.75，并高于负样本至少 0.04；最佳人物领先第二名至少 0.08。阈值沿用现有保守策略，不是校准后的置信概率。
- 用户确认的归一化 256 维、至少 3 秒干净声音才能教给声纹库。自动匹配不回流成为确认样本。纠正 A → B 同时撤回 A 的正例、添加 A 的负例和 B 的正例；改回可撤销同一证据的错误负例。改名、纠错、删除后重新判断已有声纹观察。
- 匿名分组继续使用有上限的归一化平均中心。短片段可复用临时组 ID，但不移动可信中心；后续可信中心可吸收无明确冲突的短组。组间相似度接近时不强并。
- 同一识别窗口的不同本地说话人写入不能合并的约束，后续短组吸收保留约束。明确人工确认不被自动归并覆盖。
- 模型版本隔离，未增加模型、LLM 或云端上传路径；WeSpeaker / Core ML 执行路径保持不变。

## 迁移与边界

数据库 13 → 14 增加按人物的排除证据与组间冲突表，迁移既有“不是我”负例。前台资料恢复时执行一次标签/短组升级，不改正文、音频、手动确认和识别任务的 generation。

说话人选择面板不显示声纹学习说明。历史转录没有声纹观察时仍可手动命名，在设置的人物列表中显示 0 个有效样本；不通过文字或显示姓名伪造声纹学习。此次不重新转录这些旧音频，也不声称其已被自动认出。
