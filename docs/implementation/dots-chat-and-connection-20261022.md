# 聊天与初次连接：1.22.0

独立分支 `codex/hermes-app-20261021`。不合入 main。手机仍只负责采集、阅读与远程聊天，Hermes 原生记忆机制沿用 1.21.0。

## 面向初级 geek 的入口

长期使用推荐固定 HTTPS 入口，临时地址只用于体验和验证。首次连接页提供两条明确路径，不要求用户先去设置找网络配置，也不会在用户选择前自动开启公网入口。

- **长期使用**：App 内解释隧道的作用，展示当前运行时唯一应转发的本地连接服务地址，给出固定隧道的三步教学与官方文档。填写固定 HTTPS 地址后检查端点身份，再生成二维码。目前用户自己管理服务商账号、域名与连接器，App 不自动安装 cloudflared 服务。
- **先体验**：自动使用系统 SSH 建立 localhost.run 入口，无需账号或手填参数。地址会变化，手机要重新扫码更新；不承诺临时域名变化后手机能在异地自动发现新地址。
- **暂不连手机**：可以先用 Mac，之后从设置进入同一连接流程。

连接层与 Hermes 分离。固定入口不能缓存/缓冲 SSE，也不能要求手机客户端进行浏览器登录。Cloudflare Quick Tunnel 不支持 SSE，不作为这版的聊天连接。固定 Cloudflare Tunnel、ngrok 或自建代理可以按当前接口接入；本轮未配置真实固定域名，不将适配设计等同于这些服务全部实测通过。

来源：[localhost.run 免费入口限制](https://localhost.run/docs/forever-free/)、[Cloudflare 固定隧道](https://developers.cloudflare.com/tunnel/get-started/)、[Quick Tunnel 限制](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。

## 故障与恢复

`TunnelLifecycle` 保存启用意图，App 重开后恢复上次主动开启的连接；主动停止则保持停止。后台检查不依赖打开设置页面。临时 SSH 无地址、退出或持续不可达，30 秒后清理旧进程，以 5–120 秒退避重试。固定入口不可达只继续检查，不代替用户安装或重启连接器。

邀请过期或地址变化时作废，授权成功后隐藏已消费二维码，显示手机连接状态。设备凭据、workspace/assistant/instance 身份、运行记录与记忆不会因隧道更换而重建。服务关闭会结束自己创建的 SSH 进程；原有授权设备可以从设置撤销。

SSE 上游不再继承普通 HTTP 的 10 秒整响应超时，改用连接超时与 45 秒空闲读取超时，继续使用原有事件回放与任务快照。不是新建一套临时地址轮询协议。

模型首次启动等待延长到 60 秒并持续显示进度；手机在成功验证和持久化新连接后才替换现有聊天与转录同步，写入失败保留旧运行对象。

## 验证记录

使用单独 iPhone 17 Pro / iOS 27 模拟器和隔离的合成资料/模型。Mac 原生界面操作、真实内置 Hermes、MCP、系统 SSH 与公网 HTTPS 均参与验证；没有使用用户手机或个人转录。

初轮模拟器关闭签名导致钥匙串写入失败；改为 Xcode 正常生成模拟器 ad-hoc 签名后，公网二维码导入、Mac 允许、手机验证与重开恢复通过。没有降低应用密钥保护或改用明文保存。

初轮聊天测试仍按旧流程直接等待输入框，实际停留在首次欢迎页；测试改为走完真实欢迎与连接确认。合成模型也补齐了 streaming 格式，避免用普通 JSON 响应冒充 SSE。最终验证与截图详见随交付的 `momoagent-product-dogfood.html`。

最终验收：33 项 Python、23 项 Swift 客户端、19 项 JavaScript 渲染核心、8 项 iOS 渲染宿主测试通过。公网扫码配对 UI 与转录记忆/聊天执行 UI 各 1 项通过。后者验证真实中途回复、展开后的录音工具记录、停止按钮、关闭手机进程后 Mac 写入文件、恢复原 run ID 与草稿。工具步骤采用 Hermes 返回的真实工具名，模型等待下一轮时不强行断言瞬时“工具执行中”。

公网 HTTPS + SSE 在人为延迟 14 秒后收到首条回复（15.05 秒），任务成功保存文件，重复提交返回相同 run，撤销凭据后拒绝访问，主密钥不能用于公网入口。测试期间临时隧道确实短暂不可达；Mac App 重开后恢复 Agent 并经退避恢复公网入口。固定域名未实测，不能用这次结果推导长期可用性。

Mac Debug、手机 Release 与嵌入 Watch/Widget 构建通过；最终 Release 静态包审计通过。Mac 测试复用准备好的隔离 Python 环境，没有验证全新机器首次下载。测试后已退出 App、关闭合成模型与隧道并删除本轮专用模拟器。

静态设计检查的两项命中是已有 Markdown 引用线与活动文字 shimmer，分别服务内容引用和运行状态，保留，不属于新增装饰卡片或渐变标题。

真实手机 HealthKit 授权与远程接线、CuaDriver 系统授权、固定域名长期运行、正式签名发布、附件远程发送及旧 Pi 历史迁入仍待完成。构建和模拟器通过不等于这些工作已交付。
