# 已有文字先总结

版本：1.8.4。

## 行为

持续录音、等待同步、部分识别失败时，已收到的可读文字也能生成总结。总结沿用原有自动生成门槛：至少 20 个有效字符，或用户标记且已有可读文字。更短的片段直接显示正文。

总结只依据当前已有文字。后续正文新增、修改或删除后，内容版本变化，旧总结失效并重新生成。只有处理进度、原音可用性或结束回执变化时，保留仍有效的总结。没有可读文字时不请求模型。

总结直接写事情、决定或安排，通常一句、中文 30–60 字，最多 80 字。缺失部分不推测，不写“转录里讲了”、资料完整性评价或“点击查看原文”等建议。该规则由模型请求约束；不通过截断或关键词替换改写模型输出。

总结尚未生成、未配置模型或模型暂时失败时，时间轴先显示已有正文。真实同步与识别状态继续由状态标签和详情里的来源问题展示，不再替代正文预览。

总结缓存增加格式版本。旧格式不再直接显示，自动队列在升级后重新扫描历史日期；使用用户保存的模型连接重新生成。原音与原文不修改。队列串行执行、沿用有界重试，按正文版本退避，进度变化不会绕过同一内容的退避。

移除时间轴中的“间隔约 X 分钟”，保留时间范围、说话时长、从早到晚的排列和首次进入滚到最底部的行为。
