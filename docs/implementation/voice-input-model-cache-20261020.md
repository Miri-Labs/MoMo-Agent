# 语音输入与模型校验缓存

本次保留现有前台预热、三个输入尺寸和模型实例复用策略。仅减少重复的完整模型文件哈希，并在聊天输入框增加本地语音转文字。

## 模型校验

模型仍保存在 `Library/Caches/MoMoAgent/SpeechModels/<manifest-hash>`。首次完整校验成功后，保存 `.validated-model-v1.json`，记录清单身份和每个文件的设备号、inode、大小、mtime、ctime。

后续启动读取这些文件属性。全部匹配时复用完整校验结果，不读取模型权重。文件变化、校验记录缺失或损坏时重新校验。完整校验失败时保留原有的源模型校验、临时复制和原路径原子发布流程。取消请求在快速路径中同样有效。

该快速路径用于应用自行管理、正常使用期间不修改的模型缓存。ctime 可以发现同大小写入以及恢复 mtime 的文件修改。它不是每次启动都执行的内容完整性校验。系统清理缓存后会重新准备；写入校验记录失败不影响使用刚刚通过完整校验的模型。

## 聊天语音输入

参考 2026-10-20 Claude 网页实际加载的听写组件，包括独立麦克风入口、结束识别状态、取消、错误后重试及草稿保留。参考地址为 [Claude 新对话](https://claude.ai/new)，相关组件位于该页面的 `shared-9-CLmitdTB.js`。实现使用 SwiftUI，沿用 MoMoAgent 的颜色和输入框样式。

- 点击麦克风后申请权限，停止本应用回听，再开始录音。
- 输入框内显示真实麦克风音量、计时、取消和完成按钮。音量只在录音时以 12.5 Hz 更新，限于小型波形视图。
- 最长录音两分钟。点击完成或到达时限后，复用现有 `SpeechEngine`、本地 VAD 和 SenseVoice 模型转成文字。语音输入与历史转录共用串行识别队列。
- 文字追加到当前草稿，由用户编辑和发送。语音输入不发送消息、不上传原音、不创建时间线录音。
- 取消、切换会话、打开历史、离开页面或进入后台时取消当前输入。晚到的权限和识别结果不能重新开始录音或写入新会话。
- 本地临时原音在完成或取消时删除，麦克风会话随之释放。系统中断录音时尝试识别已经录下的内容；无可识别内容时保留草稿并允许重试。
