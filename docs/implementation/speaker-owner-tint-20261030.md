# 本人说话人标签的绿色样式

用户要求本人标签使用绿色或浅绿色。`SpeakerFeedbackMenu` 根据 `attribution.isUser` 使用现有 `MoMoPalette.success` 与 `successBackground`：浅色下为浅绿底、深绿文字，深色下为深绿底、浅绿文字。文字和下拉箭头同色；已识别本人及手动标记本人使用同一规则。其他人物和匿名分组沿用原样式。

时间右侧的位置、胶囊尺寸、44pt 点击区域、姓名文字、可访问性值与纠正入口保持既有行为。颜色由当前 attribution 派生，纠正为其他人后回到原样式，不单独缓存身份状态。

两套资产颜色的对比度分别为 5.64:1 与 7.38:1。验证使用既有默认字号说话人纠正 UI 流程，并保留“我”状态的真实截图；没有新增重复实现逻辑的测试。交付版本继续为 0.0.1，内部构建号 15。详细构建、UI、包验证及安装状态在本次交付证据中分别记录。
