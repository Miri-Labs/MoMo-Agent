# 手机与手表版本统一

日期：2026-10-17。基线：`aabbac8`。

用户要求版本采用 `x.x.x`，不显示括号构建号。本轮将当前版本定为 `1.0.1`，内部构建号递增到 10。

## 变更

- 原来 `project.yml` 的版本为 `0.1.0`，两端 Info.plist 又将可见版本写死为 `1.0`。现在统一在 `Config/App.xcconfig` 管理，Debug 与 Release、手机与手表共用。
- 两端 Info.plist 通过 `MARKETING_VERSION` 和 `CURRENT_PROJECT_VERSION` 获取值；工程不再重复设置。XcodeGen 2.46.0 已重新生成工程。
- 手机设置新增版本文字；手表“更多”移除构建号。两端都只读取实际 App 包中的三段版本号。
- 仓库规则与构建说明固定修复、功能更新、重大改版的递增规则。新构建的内部编号单独递增，不在面向用户的版本中拼接。
- Release 检查器读取当前共享配置，核对真实手机和内嵌手表产物。缺字段、旧版本、括号格式、两端不同或命令行覆盖导致的产物差异都会失败；报告保留两端实际值和预期值。
