# AI 服务配置编辑

首次配置现在直接显示模型 ID 输入框。模型、服务名称、API 地址、接口协议和密钥在同一页编辑，底部固定显示“验证并保存”。已有连接使用同一表单并预填当前值；密钥留空继续使用钥匙串中已保存的密钥。

“从服务获取模型列表”是可选操作。选择目录中的模型后返回表单，再由用户保存。目录不支持访问或请求失败时，可以返回手动填写模型 ID。手动保存直接验证模型与工具调用，不请求模型目录。

保存沿用已有的验证凭证和配置提交流程。验证失败保留编辑内容与原连接；修改成功后更新同一个连接，不新增重复连接。存在未保存修改时隐藏“使用已保存的模型”，避免用户误以为该按钮会保存当前输入。字段错误定位到对应输入框，网络或模型验证错误显示在保存按钮旁。
