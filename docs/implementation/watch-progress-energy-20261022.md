# 手表录音的进度通知与安静波形

基线：`f047927e`。交付版本：1.19.6。此前的缓冲复用、游标写盘和后台同步检查优化继续保留。

## 改动

编码器约每 200 毫秒报告一次进度。此前每次报告都会唤醒主线程，修改可观察录音状态，并检查手机状态发布与小组件更新。显示到秒的录音时长无需在同一秒反复通知；标记定位和故障检测仍需要最新的采样位置。

`CaptureProgressDelivery` 现在保留每次编码器报告，按采样帧对应的整数秒合并主线程通知。第一次有效采样、分片保存和任务结束立即通知。分片保存标志不会被后续普通进度覆盖，结束时会交付不足一秒的尾部。该类型移入录音模块，便于直接检验跨线程交付行为。

手表标记、时长、同步状态和故障记录直接读取最新报告。看门狗仍记录每次编码进度到达的时间，沿用原有检查周期和故障阈值。波形继续使用独立的音量通道。采集、编码、分片保存、传输批次和抬腕同步未改变。

可见波形此前即使没有可见变化，仍不断赋值 `history`，导致 SwiftUI 更新。现在将低于现有点阵显示阈值的音量与衰减归零，仅在历史数组改变时发布。新声音仍立即进入波形。阈值只用于显示，不参与原音采集或 VAD。
