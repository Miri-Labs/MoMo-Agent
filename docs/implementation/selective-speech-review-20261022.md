# 选择性语音复核

此页记录 1.19.10 的历史实现。1.19.11 已取消独立补检，当前策略见 [常规语音选择](normal-speech-selection-20261023.md)。

日期：2026-10-22。代码版本：1.19.10。此轮修改代码并在 Mac 运行真实模型和生产转录协调器；没有安装应用，也没有重跑手机历史录音。

## 修改内容

上一版给所有 VAD 拒绝范围生成 ASR 窗口，只跳过精确为零的数字静音。环境噪声因此也消耗识别算力。此版保留 Silero v6 的语句边界，增加低成本声学检查，只补检有声学证据的候选范围。

1. 原音连续解码一次。Silero v6.2.3 仍通过 sherpa-onnx 运行，权重和量化方式不变。
2. 同一份 PCM 输入 libfvad 的 WebRTC VAD。使用 mode 0、16 kHz、20 毫秒帧；不加载额外神经网络，不创建线程或另一套推理运行时。
3. 按连续 20 秒范围累计声学证据。连续检出 200 毫秒即可保留短回应；分散的证据按 5% 累计比例判定，完整范围需要 1 秒，短的已接收尾部至少需要 100 毫秒。两条条件满足任一条即可进入补检。
4. 保留 Silero 已选中的全部语句；从补检候选中扣除已有语句，避免重复识别。其余范围直接提交非语音处理进度。
5. ASR 核心窗口最长 20 秒。保留既有语句边缘、跨窗口上下文、时间戳归属和相邻结果对齐。SenseVoice 批次最多两个窗口，Nano 原版仍为 batch 1。

20 秒是分析范围，和手表同步周期无关。输入框实时语音保持独立队列，不运行这层补检，也不等待凑批。手表不链接识别或声学检查库。

新增依赖仅为静态编译的 libfvad C 源码。固定上游 revision、逐文件 SHA256 和许可证见 [依赖说明](../../Native/SpeechVendor/README.md)。没有添加完整 WebRTC 框架。

## 连续性与历史

`continuousArchive` 取代含义过宽的 `verifyVADRejections`。连续归档、上下文拼接和历史继承不再依赖“全部间隙送 ASR”。

- 两种检测器都随录音 epoch 保留状态，不随文件、读取块或调度任务重置。
- 补检范围随检查点裁剪，只保留仍需要的部分。
- 分页提交时同时保存已跳过范围，避免取消后从头分析噪声。
- sherpa 内部时钟切换时，原生 Flush 可能少返回最后一个 512 点帧。切换前保留已消费的真实帧，避免人为造成 32 毫秒断裂。热身重放后的端点允许一帧检测差异；测试检查实际识别上下文仍覆盖参考语音。
- 新策略先继承上一版全量核验结果，再处理直接从 v4 升级的情况。已完成正文和旧的非语音范围不重新识别。

## 对照结果

使用 11 段既有本地录音副本，共 660 秒。两种策略使用同一模型、同一生产协调器、独立临时 SQLite 资料库。全量对照仅在忽略目录的源码副本中恢复“所有间隙进入 ASR”，保留相同诊断和声学扫描，以测量窗口选择策略的差别。没有写回手机。

| 指标 | 全量对照 | 选择性复核 |
| --- | ---: | ---: |
| 原音总时长 | 660 秒 | 660 秒 |
| 选中核心范围 | 660 秒 | 560 秒 |
| 跳过范围 | 0 秒 | 100 秒 |
| 实际 ASR 输入，含重叠上下文 | 713 秒 | 606 秒 |
| 原生识别耗时 | 12.67 秒 | 10.95 秒 |
| 协调器处理总耗时 | 18.99 秒 | 16.89 秒 |

实际 ASR 输入减少约 15%，此轮总耗时减少约 11%。这是一轮 Mac 对照，不能换算为 iPhone 耗电或吞吐承诺。样本经过问题筛选，不代表全天声音分布。

早期仅按累计比例判定的版本能跳过 160 秒，但可能排除短回应，未采用。最终版本增加连续短语音条件；320 毫秒公开语音片段的独立检测用例确认，它不必累积到一秒才进入识别候选。

6 段语音样本的正文字符数与全量对照一致，5 段噪声对照均无正文。字符数不能证明逐词准确率。这批私人样本没有人工逐词标注。

公开中文夹具用于逐字验证单句、跨文件和连续重复语句。另一个夹具把音量降到约十分之一并加入非零底噪：选择性处理保留了直接识别原音的文字，并跳过远离语音的噪声；两种识别都存在“开放 / 开饭”同音错误。该用例验证没有新增分段损失，不作为 ASR 准确率达标证据。

## 验证和限制

回归覆盖没有声学证据时不创建 ASR 工作、非零噪声完成进度、声学分帧和快照边界、跨文件与超过两分钟的连续语音、取消重建、后续分片到达、原生时钟切换和跨版本历史继承。公开语音用例保留原有逐字断言。

Mac 相关回归共 45 个测试函数通过；最后加入短回应条件后，受影响的 16 个测试函数再次通过，包含参数化用例。新增 C 源码通过 iPhone arm64、iOS 18、C11 编译检查。此轮没有生成或安装完整 iPhone / Watch 应用包。

`SpeechDiagnostics` 新增选中时长、跳过时长和实际识别输入时长；字段可缺省，兼容旧诊断 JSON。运行方式见 [PhonePipelineReplay](../../Tools/PhonePipelineReplay/README.md)。

两种 VAD 仍可能同时漏掉极短或极弱的语音，声学阳性也可能包含噪声。此次优化减少了全量 ASR 的浪费，没有证明所有环境都零漏检。真实手机每小时五分钟内的处理目标，以及温度、峰值内存和耗电仍须真机验收。

复现材料位于已忽略的 `tmp_agent_output/vad-recall-efficiency-20261022/`，包括全量对照源码副本、模型实验、诊断计数和测试日志。原音、私人正文和资料库不提交仓库。
