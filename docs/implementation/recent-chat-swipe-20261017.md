# 最近聊天的侧滑抽屉

2026-10-17 用户确认：从屏幕左边缘向右拖出最近聊天，向左拖动收起。沿用原有侧栏宽度、内容和遮罩。

## 实现

- 只有聊天根页面接受左侧 24pt 内起手的向右横拖；转录、设置、录音详情及首次体验保留原有手势。
- 抽屉和遮罩随手指更新。松手时结合位移与释放速度选择展开或关闭，再用弹簧动画落位；短拖可取消，支持反向拖回。
- 横向意图在原生手势识别阶段判断；纵向拖动交给聊天和历史列表。已接受的横拖可与原生或 WebKit 滚动识别器同时识别。
- 拖动状态由 `ChatHistoryDrawer` 管理。拖动中不修改会话、不触发列表刷新；确认展开后沿用已有刷新入口。
- 保留菜单、遮罩点击和 VoiceOver 关闭操作。关闭后清空侧栏搜索并将读屏焦点还给菜单。减少动态效果开启时，取消落位动画，直接拖动仍跟随手指。
- 页面、场景和宽度变化会清除临时拖动。手势被系统取消时恢复原来的展开状态。

设计参考：`docs/design/iphone-review-20261015/HANDOFF.md` 第 3 节；采用原有 300/393、最大 340pt 的宽度与 33% 遮罩，本次仅补充连续拖动。

本轮没有向手机安装，也没有修改录音、传输或聊天恢复逻辑。
