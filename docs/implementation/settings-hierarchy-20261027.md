对应[设计与 Typeless bundle 复核](../design/settings-hierarchy-20261027.md)。保持 Mac 的连续画布和开放行、手机原有 MoMoPalette；本轮只调整层级、文案、控件对齐和弹窗尺寸。应用源码提交 `644c0be2`，交付版本 **1.36.4**；内部诊断构建号 157。

## 实现

- Mac 设备页合并网络管理。远程访问标题和状态在左、原生开关在右；取消独立“状态”行。设备、地址、模型、权限和通用操作均显式左右布局。
- 连接方式在设置内容区原地展开，右上角返回，Escape 同样返回设备页。日常管理使用开放行和右侧 36pt 胶囊；首次配对保留原引导。
- 移除连接方式 480×520 固定 sheet。配对按内容测量并限制滚动上限；权限窗口按 fittingSize；记忆详情按内容高度、长文最多 360pt 滚动。录音原文阅读器保留 640×600 文档视口。
- 手机设置分为 MoMo、个人资料、转录与储存三组，取消高级设置中转。连接状态和网络原地展示；手动输入另页。记忆同步有内容才展开，无详情时只显示状态。健康和其他资料仍保留授权范围、AI 使用与撤回说明。
- 保留原状态所有权、异步任务、错误、授权与删除确认；没有修改用户数据结构、Bundle ID 或配对协议。
- Pen 同步模型、设备、记忆、通用、连接方式及手机设置画板，增加 `G2lJAg` 自建服务器原地表单。
