## 适用范围

本政策适用于 MoMo Agent 的 iPhone 与 Apple Watch 应用。MoMo Agent 用于手表录音、向配对手机传输录音、手机本地转写和管理记录，以及使用你自行配置的第三方模型服务进行助理对话。使用本地录音和转写不需要创建 MoMo Agent 账号，也不需要模型 API Key。

## 本地处理的信息

- **录音与记录信息**：你开始录音后，Apple Watch 采集声音，保存音频分片、录音时间、标记和传输状态，并通过 Apple Watch 与 iPhone 的 WatchConnectivity 机制传输到配对手机。传输可能延后，不保证立即完成。
- **转写与资料**：iPhone 使用随应用提供的 SenseVoiceSmall 与 Silero VAD 模型在本机处理音频，保存转录文字、时间和来源引用、处理状态及相关资料。该转写流程不调用云端语音转写服务。
- **聊天与助理设置**：聊天记录、助理生成的内容、个性设置、“关于你”和“长期记忆”等内容保存在手机。助理可通过本地工具按你的请求更新个人资料与长期记忆；你也可在设置中修改或清空这些内容。
- **连接与配置**：应用保存设备／资料库标识和同步状态以协调配对设备间的接收、重试和删除；这些标识用于应用自身运行，不是广告标识。已保存的 AI 服务连接名称、模型地址、模型 ID 和接口配置保存在手机；每个连接使用独立引用，将 API Key 保存在该设备的系统钥匙串。

当前应用代码没有接入广告、广告追踪、开发者运营的账号系统或远程统计分析／崩溃上报服务。开发者没有通过上述功能接收你的录音或转录资料。第三方模型服务的数据处理另见下一节。

## 第三方模型服务与对外发送

助理模型服务由你在“设置 → AI 服务”中配置，并使用你自己的 API Key。未配置时不预选服务商或模型；你可以保存多个连接并选择当前使用的连接。预设只填写地址与接口协议，不选择模型，也不代表已建立连接。自定义服务需要填写地址并明确选择协议。连接并读取模型目录后，由你选择模型或填写模型 ID，再验证并保存使用。请求从手机直接发送到配置的地址，不通过 MoMo Agent 开发者的模型中转服务器。模型服务可能按你的账号收取费用。

读取模型目录会向你配置的服务发送鉴权请求。模型验证会向所选模型发送小型合成提示、随机校验值与工具定义，以检查结构化工具调用能力。这两种操作不读取或发送你的录音、转录或聊天记录；返回的验证工具调用只用于校验，不会执行。模型验证可能产生少量 API 费用。

发起助理请求时，发送的信息可能包括：

- 你输入的消息、相关聊天历史、模型回复及后续工具交互；
- 助理性格、“关于你”和“长期记忆”的内容；
- 选中录音的转录片段，以及自动选取的近期转录片段；
- 录音时间、来源标识、引用、资料处理状态、时区及请求时间等上下文；
- 助理调用本地搜索、列举录音或读取转录工具所取得的文字和相关元信息。工具读取可涉及早于自动近期窗口的资料，并不限于你手动选中的录音。

当前自动近期正文窗口为请求前两小时；初始上下文也包含最多八条录音概况。此限制不是整个对话的资料范围上限，后续工具读取和聊天历史可能带入更多内容。开始录音或完成本地转写本身不会自动发起模型请求。助理请求和工具播放不自动把原始音频上传给模型服务。

API Key 作为请求鉴权信息发送给你配置的服务。该服务及其网络基础设施还会接收建立连接所需的信息，例如来源 IP 地址。请仅配置你信任的服务地址，并查看该提供方关于存储期限、训练用途、处理地点、删除和安全的政策。处理地点取决于你选择的服务，可能位于境外；选择预设不代表对服务商实际处理地点的保证。MoMo Agent 无法保证不同服务商具有相同的数据处理方式。

## 权限、导出与设备文件

Apple Watch 在录音时使用麦克风权限；你可以在系统中撤销该权限，撤销后不能继续录音。界面提供录音、暂停／恢复和结束操作。请在录制他人声音前取得适当许可。

你可以在手机录音详情中导出转录（Markdown 与 JSON）、音频分片或两者，并使用系统文件／分享界面选择接收方。手机开启文件共享和文档原位访问；能访问这些文件的人员、电脑或你选择的应用可能读取或复制资料。导出到云盘或其他应用后，其副本受相应服务的规则管理。

## 保存、删除与安全

原音默认保留七天，可在设置中调整为一至三百六十五天；符合已确认接收、完成处理等条件的原音在应用运行清理流程时到期清理，标记为“原音不自动清理”的录音不参与该自动清理。自动清理原音不会自动删除转录文字。

你可以在录音详情中删除录音与转录。应用会清理关联助理上下文，并向手表传递删除控制信息；离线、未连接或处理失败时，手表侧清理可能延后。修改或清空个性与记忆不会删除已有聊天或正在恢复的请求。应用没有承诺统一的“清除全部聊天和密钥”按钮。

本机删除无法撤回已经发给模型服务的数据，也不能删除已导出、分享或由其他服务保存的副本；请向相应接收方申请删除。停止使用助理可避免发起新的主动对话，但已发出的请求、进行中的工具轮次或可恢复请求需要另行取消和核实。需要使某个 Key 失效时，可在模型服务提供方撤销它；仅卸载应用不能保证清除系统钥匙串中的凭据。

应用使用系统沙盒、HTTPS 模型地址校验及系统钥匙串等保护措施。iPhone 资料库文件设置了文件保护及备份排除，但不能据此保证所有助理文件、导出副本和设备备份都被排除，也不承诺端到端加密或绝对安全。请妥善保护设备及所导出的资料。

## 联系与政策更新

有关访问、更正、删除、个人信息处理或本政策的问题，请通过上述隐私邮箱联系开发者。请勿在首次联系中发送完整 API Key 或不必要的录音内容。若处理方式发生变化，我们会更新本政策；需要另行取得同意的处理，将在适用要求下另行告知并取得同意。
