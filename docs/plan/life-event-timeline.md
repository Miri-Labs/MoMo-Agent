# 生活事件轴

范围：把已授权的手机到访地点、系统日历计划、录音实况放到同一时序中，供聊天自动上下文及只读工具使用。不加入待办、文件和照片，不另建事件轴页面。

- 地点从用户开启后使用 Core Location Visits 收集，保留坐标、精度、到达/离开时间及收到报告的时间。系统可能延迟报告；未知离开时间不能表示仍在原地。不运行持续 GPS，不逆向猜测商家或家庭地址。
- 日历沿用系统连接权限，另由用户开启事件轴上下文；保留原时区和全天标记，明确只是计划。
- 录音按原始采样映射的时间检索，跨午夜或持续多日仍可查。摘录携带可验证的原始引用。
- 默认提供最近 6 小时到未来 18 小时的有限概况，按来源分配条数。工具允许最多 7 天的范围，按时序分页；截断和各来源失败单独标明。
- 停用位置或日历上下文后，后续模型输入隔离此前含这些资料的聊天历史。本地聊天仍可回看。位置记录可单独清空。
- 设置持久化失败要呈现；收集失败不影响录音。所有读取在短生命周期内完成，不在模型请求期间持有文件或数据库事务。

验证：真实 SQLite 录音时间查询、到访合并与恢复、授权撤销/清空、来源部分失败、时区/分页/预算以及 iPhone 编译。真机背景到访的延迟和耗电另行观察。
